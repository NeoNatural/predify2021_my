# Hebbian-CNN
Introducing short-time Hebbian learning into CNN for Priming Effect (repetition sharpening and suppression)

The maintained runner is now configured from
`../configs/hebb_vgg_priming.toml` and can be launched from the repository
root with `python -m predify_experiments`. The two historical
`Hebb_VGG_Pred_Run*.py` filenames remain as lightweight compatibility entry
points.
