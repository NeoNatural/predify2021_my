# 完整图册：156张图

包含ImageNet四类和THINGS五类的三套读出、clean/noisy、三种记忆模式、四种预览内容，以及四层激活和sharpening。所有图均另存PNG和SVG。

ACC机会水平分别为25%和20%；macro OVR ROC-AUC机会水平均为0.5。自适应轴压缩区有灰底及倍率，不能用视觉斜率判断速度或显著性；线性核对图同时提供。差值以同模式different-category为基线。绘图中的后期放大为t5–t14，统计表的late窗口仍为预定t10–t14。
