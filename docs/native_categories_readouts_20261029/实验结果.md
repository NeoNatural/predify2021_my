# 原生类别扩样与两套t9读出：实验结果

> **2026-11-02更正：** 历史清单漏检独立FC实验：THINGS正式目标中37个概念、106张图片，ImageNet中47个概念、34张图片曾在旧FC研究出现。“全新概念”“未用目标图”表述不成立；此轮为探索性扩样研究。[详细审计](历史覆盖补充审计_20261102.md)。

已完成35280条target轨迹（34560条正式条件＋720条唯一clean参考）和3670个CV分类器；开发验收另计。

THINGS：五类、100个概念、400张正式目标；ImageNet：四类、80概念、320张目标图，其中一部分概念曾用于历史实验（详见数据验收表），本轮为扩样探索研究。植物开发队列经用户确认改为1概念，其余每类4概念。

MVPA保持逐条件、逐时刻、概念分组五折训练。t9-A按模式和噪声独立拟合，四种内容合并等权；t9-B每图一份无记忆clean t9参考，迁移到全部条件。B下降可反映分布与边界不匹配，不能据此声称信息减少。
