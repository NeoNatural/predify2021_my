# 五步抑制后的单次 Hebbian 增益

## 实验设置

比较 ε=0 与 ε=0.005。每个 target 先沿用 λ=0.03 的五步仅抑制，得到 $p$，再读取同一份冻结记忆。用 $u=\tanh(q(p,W)/c)$ 得到增益方向，按 $p$ 加权中心化，输出 $y=p[1+\varepsilon(u-\bar u_p)]$。FC 对整张图中心化，Conv4 对每个空间位置的 512 个通道中心化。全零组输出零。

- FC 沿用轻量 SAE、训练折定标与两帧 vanilla preview 表征缓存。两层分别从 preview 写入两次。FC1 输出经过原线性权重、bias 和 ReLU 得到 FC2 的实际输入。FC1 输入为同一份 vanilla FC1，记录于无 Hebbian 基线。固定 SVM 沿用原始训练折分类头。另为每个数据集、每层用训练折拟合一个跨两种 ε、三个历史共享的 SVM。每种历史权重相同，每种 ε 权重相同。
- Conv4 只用原通道 rep4 建图、作用于 rep4。两段 preview 各两步，每段结束写入一次。两组用同一条仅抑制 preview 路径，每个 target 步先抑制再施加一次增益，并将结果送回网络。复跑 t0–14。固定 SVM 沿用训练折的原 FC1、FC2 读出。
- 两组共用训练侧末态尺度 $c$。合并训练 Exact 与 Different，在 $p>0$ 的单元上计算 $q$ 的 RMS。FC 使用 256／320 个 ImageNet／THINGS 训练目标，Conv4 使用原训练子集的 24／30 个目标及所有 target 时间步。定标尺度 $c$、已有 κ 定标和 Conv4 原 rep4 归一化均在复核前冻结。ImageNet／THINGS 的 clean 开发批量分别为 FC 16／18 个目标和 Conv4 16／20 个目标。

活动按原实验口径汇总。重复抑制为逐目标 $100(1-\mu_{\mathrm{Exact}}/\mu_{\mathrm{Different}})$ 的加权平均，FC 按类及概念平衡，Conv4 按目标平均。类别几何取逐图 L2 归一化后的类内散度、类间散度与两者之比 Fisher。卷积先算各网络步的指标，再按窗口取均值。卷积准确率按逐时间步的预测计算并取窗口平均。卷积 AUC 使用窗口平均分数，margin 为逐步真实类别分数减最大其它类别分数后取窗口平均。

区间为按类别分层的 4,000 次配对概念块重采样的 95% 百分位区间。一个概念的目标、两种 ε、两种历史及所有时间步同进同出。区间用于描述这批已反复使用的开发样本，未作多重比较校正。FC 的无 Hebbian 对照是两种历史共用的原前馈表征，Conv4 则使用各自相同 preview 历史的既有无 Hebbian 对照。

## 局部验收

固定每个 target 步的 $p,W$ 时，$\sum p_i(u_i-\bar u_p)=0$，因此增益前后活动总量相等，Exact 与 Different 的活动比值也相等。独立 FP64 复算中，活动总和的最大相对误差为 $4.29\times10^{-16}$。实际 FP32 的误差如下。

| 范围 | 每组活动总和最大绝对误差 | 每组最大相对误差 | 逐图总和最大绝对误差 | 逐图最大相对误差 | 逐目标重复抑制最大差，百分点 |
|---|---:|---:|---:|---:|---:|
| FC1、FC2 | 5.01e−6 | 3.46e−9 | 5.01e−6 | 3.46e−9 | 4.24e−7 |
| Conv4 原通道 | 2.43e−5 | 6.68e−8 | 1.10e−4 | 2.47e−9 | 3.21e−7 |

所有实测单元的非负性和非零支持通过检查。正单元的乘性因子介于 0.994315 与 1.004957；全零组用构造输入验收。FC ε=0 逐元素复现了已有仅抑制输出。Conv4 ε=0 的活动、归一化 Gram 和 FC 表征复现已有仅抑制归档，最大差为零。记忆每 trial 清零、两段 preview 后写入数为二，所有 target 更新均通过权重冻结检查。

## 固定抑制末态时的局部类别几何

下表是同一个 Exact 末态上，ε=0.005 相对 ε=0 的百分比变化。Fisher 后附配对概念块区间。

| 数据集 | 层或时间窗 | Δ类内散度 | Δ类间散度 | ΔFisher [95% 区间] |
|---|---|---:|---:|---:|
| ImageNet | FC1 | +0.0264% | +0.0121% | −0.0143% [−0.0250, −0.0021] |
| ImageNet | FC2 | +0.0190% | +0.0131% | −0.0059% [−0.0366, +0.0287] |
| THINGS | FC1 | +0.0191% | +0.0109% | −0.0081% [−0.0230, +0.0014] |
| THINGS | FC2 | +0.0162% | +0.0131% | −0.0031% [−0.0173, +0.0172] |
| ImageNet | Conv4 t5–9 | −0.0338% | −0.0246% | +0.0091% [+0.0003, +0.0183] |
| ImageNet | Conv4 t10–14 | −0.0338% | −0.0248% | +0.0090% [+0.0002, +0.0183] |
| THINGS | Conv4 t5–9 | −0.0259% | −0.0254% | +0.0005% [−0.0040, +0.0128] |
| THINGS | Conv4 t10–14 | −0.0260% | −0.0255% | +0.0005% [−0.0041, +0.0128] |

固定活动后，FC 的类内散度仍上升得更多。Different 的四组 FC 结果也都出现 Fisher 下降。Conv4 的两项散度同时收缩。ImageNet Exact 的类内收缩更大，产生约 +0.009% 的局部 Fisher 改善。THINGS Exact 的类内、类间收缩幅度接近，Different 的类间收缩更大，两个窗口 Fisher 均约 −0.0043%。

## 真实 FC 串联

Exact 的类别几何变化均相对 ε=0。重复抑制列使用 Exact 和 Different 逐目标配对。

| 数据集 | 层 | 重复抑制 ε=0 → 0.005 | Δ类内散度 | Δ类间散度 | ΔFisher [95% 区间] |
|---|---|---:|---:|---:|---:|
| ImageNet | FC1 | 0.6147% → 0.6147% | +0.0264% | +0.0121% | −0.0143% [−0.0250, −0.0021] |
| ImageNet | FC2 | 0.9077% → 0.9153% | +0.0364% | +0.0223% | −0.0141% [−0.0415, +0.0225] |
| THINGS | FC1 | 0.4093% → 0.4093% | +0.0191% | +0.0109% | −0.0081% [−0.0230, +0.0014] |
| THINGS | FC2 | 0.5909% → 0.5887% | +0.0252% | +0.0144% | −0.0107% [−0.0209, +0.0151] |

FC1 的活动守恒直接保留重复抑制。FC2 接收实际桥接后的输入，重复抑制在 ImageNet 增加 0.00764 个百分点，在 THINGS 减少 0.00217 个百分点。FC2 Exact 的 Fisher 降幅比同末态局部对照更大，两种数据集的类内扩张都更明显。Different 的四组完整网络 Fisher 点估计也都为负，范围为 −0.0225% 至 −0.0112%。

### FC2 最终读出

固定与共享重拟合 SVM 的准确率和 BA 在两种 ε、两种历史下均持平。ImageNet 的准确率和 BA 均为 81.25%。THINGS 的准确率为 77.78%，BA 为 80.00%。Different 下两种 SVM 的宏 AUC 均持平。Exact 如下，margin 为真实类别分数减分数最高的其它类别。

| THINGS | 共享重拟合 | 0.94643 → 0.94643 | 2.88176 → 2.88166 |

## 真实 Conv4 递归

Exact 的类别几何变化均相对 ε=0。递归让增益改变了后续的 Conv4 输入。Exact 的中晚期输出均值相对 ε=0 上升约 0.0012%–0.0017%，Different 上升约 0.0003%–0.0008%。四个中晚期窗口均保留正的重复抑制，抑制率小幅下降 0.00042–0.00111 个百分点。

| 数据集 | 时间窗 | Conv4 重复抑制 ε=0 → 0.005 | Δ类内散度 | Δ类间散度 | ΔFisher [95% 区间] |
|---|---|---:|---:|---:|---:|
| ImageNet | t5–9 | 0.1502% → 0.1492% | −0.0422% | −0.0318% | +0.0104% [−0.0006, +0.0211] |
| ImageNet | t10–14 | 0.1499% → 0.1488% | −0.0424% | −0.0322% | +0.0101% [−0.0009, +0.0210] |
| THINGS | t5–9 | 0.1161% → 0.1157% | −0.0324% | −0.0323% | +0.0001% [−0.0051, +0.0148] |
| THINGS | t10–14 | 0.1208% → 0.1203% | −0.0326% | −0.0327% | −0.0001% [−0.0055, +0.0146] |

ImageNet Exact 的类内收缩大于类间收缩，完整递归中仍有约 +0.01% 的 Fisher 点估计，两个区间均跨零。THINGS Exact 的两项散度几乎同比例收缩。Different 的 Conv4 Fisher 变化在两个数据集均为负，ImageNet 约 −0.002%，THINGS 约 −0.006%。相邻 Conv5 的中晚期 Fisher 点估计在两种历史均下降。Exact 下 ImageNet 下降约 0.004%，THINGS 下降约 0.023%–0.024%，类间收缩都较大。Conv5 重复抑制下降 0.0137–0.0191 个百分点。

### 递归后 FC2 固定 SVM

两个历史的逐步平均准确率和 BA 在全部时间窗均持平。Exact 中晚期的准确率、宏 AUC 和 margin 如下。Different 中期的宏 AUC 在 ImageNet 增加 1.04 个百分点，在 THINGS 中晚期均减少 0.31 个百分点。

## 历史效应与无 Hebbian 对照

ε=0.005 时，Exact 相对 Different 的 Fisher 在 FC2 分别变化 −0.0635% 和 −0.0845%（ImageNet、THINGS）。FC1 分别变化 −0.0403% 和 +0.0242%。Conv4 中晚期，ImageNet 约 −0.055%，THINGS 为 −0.028% 和 −0.026%。相对无 Hebbian 的 Exact 对照，ε=0.005 的 FC1／FC2 Fisher 低 0.146%–0.219%，Conv4 中晚期低 0.067%–0.087%。两种 ε、两种历史的活动与几何原值及全部配对变化见结果表。

## 复现

使用本项目的 `predify2021` Conda 环境，从仓库根目录运行。卷积入口读取 E 盘现有实验和训练产物。每个阶段完成两条分支后进入下一阶段。

```powershell
foreach ($stage in @('calibrate','local','network')) {
    python analysis/hebb_post_pool_20261111.py fc $stage
    if ($LASTEXITCODE -ne 0) { throw "FC $stage failed" }
    python analysis/hebb_post_pool_20261111.py conv $stage
    if ($LASTEXITCODE -ne 0) { throw "Conv4 $stage failed" }
}
python analysis/report_hebb_post_pool_20261111.py
```
