# 真正串联的 FC1 / FC2 侧向实验

2026-10-28。保留原模型及既有缓存，使用原始VGG16的FC1→FC2线性权重、bias和ReLU，把FC1侧向处理后的结果实际送入FC2。eval下dropout为恒等。这里是顺序串联：FC1完成指定步数后，结果经前馈桥接进入FC2再完成指定步数，没有增加反向反馈。

## 为什么需要重新评价

前轮两个FC分别从各自vanilla激活开始，不能用其独立效果相加预测串联。FC1改变后，FC2输入的幅度、方向和非零结构都会受原始权重与bias影响。先验证无侧向处理时线性桥接重建与原FC2缓存一致到FP32误差，再对修改后的FC1计算新的FC2输入。

## 固定参数与条件

各折沿用此前内层选择的参数：FC1正相关mutual top128、增益0.25；FC2正相关mutual top32、增益0.75；原图活动预算1.0；除法强度2。只切换soft/hard及预定步数，不根据本轮测试结果重新选参。

- baseline。
- 仅FC1侧向、仅FC2侧向；soft/hard、各1/5/20步。
- 两层都开：soft-soft、soft-hard、hard-soft、hard-hard；同步1/5/20步。
- hard-hard另完整比较FC1/FC2各1/5/20步的非对称组合。
- 仅两层抑制、去掉两层Hebbian的soft/hard对照。
- FC1逐图均值匹配缩放、FC2逐图均值匹配缩放、两层都以均值匹配缩放替代的对照。

共57条件。包含两种FC2侧向统计口径：

1. frozen：完整沿用独立FC2训练缓存估计的侧向连接与归一化尺度。
2. matched：仅用当前外层训练折中，实际经过修改后FC1和原始前馈桥接得到的FC2输入，重新估计侧向连接和尺度。

matched同时改变侧向连接统计与尺度校准，不能把它与frozen的差异全归因为连接矩阵本身。原始VGG前馈权重、bias及1000类head都固定，不进行梯度训练。

## 评价与隔离

同两个数据集和五折概念隔离。每折FC1侧向连接只由训练FC1激活估计；matched FC2只由同折实际传入的训练FC2输入估计。所有归一化、侧向统计、分类器均不使用测试概念。

分开评价：

- FC1处理后相对原始FC1。
- FC1经前馈映射造成的FC2输入变化，相对原始FC2。
- FC2侧向处理后相对当前传入FC2的输入，即第二层局部作用。
- 最终FC2相对原始FC2的整条通路总效果。

保留平均活动、归一化与原始W/B/Fisher、非零比例、招募、有效维度、零向量与塌缩诊断。两层各4096维，另报告两层等权平均活动变化，不能只用总平均掩盖某层失败。

FC2活动预算依照实际传来的FC2输入计算。因此侧向输出不增加相对该输入的活动数，但前馈桥接本身可能改变相对vanilla的密度；分别报告局部与总支持比，不强行将二者混同。

每条件最终FC2都重新拟合相同固定ridge大类readout；报告冻结原始SVM及去范数ridge诊断。十一项预定主要比较另拟合固定C=1 SVM：仅FC1/仅FC2 hard5、两层hard同步1/5/20的两种FC2口径、仅抑制hard5、双层幅度匹配的两种口径。分类准确率不要求上升，仍以平均活动下降与表征区分度提高为主目标。

ImageNet额外通过完全固定的原始1000类head检查fine-label Top1/Top5兼容性；THINGS没有对应1000类真值，不计算该项。它与重新训练的大类readout分开解释。
