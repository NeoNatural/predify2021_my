# 三区输入修订实验计划：外周退化、抗混叠、clean/noisy target 与交叉验证读出

日期：2026-10-27。

**状态：仅计划，未执行。** 本文件不修改此前冻结实验，不启动模型提取、分类器拟合、统计或绘图。以下新增参数是拟议的固定设计，不是已经验证或得到结果的设置。执行需在后续获得明确指令。

## 1. 研究问题与边界

在相同输入、初始化和计算流程下，分别研究 Hebbian-only、PCoder carry-only、联合记忆内部的内容效应：精确重复、同概念、同大类的预览，相对 different-category 预览，如何改变目标识别、激活强度及表征 sharpening。

- 三种记忆载体均保留，但**不进行载体之间的两两检验、排名或协同交互检验**。
- 每个载体内部，以 **different category = non-priming baseline**。这是“与目标类别不一致的预览”，不是“没有预览/没有记忆”。
- 删除 neutral slot；不把“无记忆”列入正式实验条件。
- 只使用共同灰屏初始化；删除 random 和直接 feedforward target-only 参照。
- Hebbian 只保留一个强度，拟沿用原主强度 **coeff=0.05**，不因已看到弱强度交互结果改选参数。
- clean 与 noisy 中央 target 都完整运行；预览的外周退化在两组中相同。
- t9 固定读出和逐时间点 MVPA 均使用交叉验证。四层激活/sharpening 全时间点记录。
- 不以计算效率为主要目标，不从结果挑最佳时刻、层、噪声或滤波参数。
- 复用已查看图像时，本轮属于**修订协议下的探索性重复测量研究**，不重新命名为独立确认。

## 3. 样本、配对与折划分

### 3.1 样本规模

为与本轮结果衔接，主方案沿用每数据集 **64张目标、32概念，每概念2图，每大类8概念/16图**。两个数据集尽量沿用此前匹配概念和图像配额。原 train/dev/test 标签不改变或删除；本次 CV 使用此前64张确认目标作为已查看的分析队列，不把原训练图混入扩大样本。

执行前核查每个概念是否仍有不属于其他目标的可用 preview 图片。若严格的预览折隔离不可实现，先提交库存缺口和替代方案；不得静默放宽隔离或自动减少条件。

### 3.2 固定五折：先分概念，再生成预览

- 以目标概念分组，按四大类分层，预先固定一次5折。
- 每类8概念可按 `[2,2,2,1,1]` 分配到五折，四类使用相同配额。因此测试折分别含16、16、16、8、8张目标，每折四类平衡。
- 同概念的两张目标、所有噪声版本、所有内容/载体、clean/noisy、全部时间点始终同折。
- t9读出与MVPA共享完全相同的折分配。
- **预览池也按概念分折**：一个概念及其所有图片不得同时出现在某折训练输入和测试输入中，包括背景 distractor。不能只检查 target 的概念。
- 折内每个大类至少准备两个可用概念，以支持 same-category/different-concept。目标概念不足两个的折，补入该折专属的 preview-only 概念，而不是借用其他折概念。
- exact 使用本 trial 的目标原图；same concept 使用同概念的另一张合格图；除本 trial 的 exact 外，其他目标图片不得作为预览使用。
- 执行前输出包含 target、prime、distractor 的完整图片/概念重叠审计。这里需要重建 preview manifest，不能直接假设旧 manifest 已满足新 CV 的视觉输入隔离。
- 不把折号、噪声或重复图片当独立生物学/统计样本。

### 3.3 clean/noisy 配对

- clean：每目标、每条件只提取一次。确定性 clean 轨迹不重复三遍冒充重复样本。
- noisy：沿用三个固定噪声种子；同一目标与种子在所有记忆和内容条件间使用完全相同的 target 张量。
- clean/noisy 使用相同 preview 图片、位置及处理后的张量。
- CV拟合中 noisy 每个噪声实现权重1/3，clean 权重1，保持每个目标的损失总量可比。
- 两种噪声水平分别拟合读出，以研究各自可解码性；因此 clean/noisy 准确率变化同时受各自拟合边界影响，不称为“同一分类器的纯抗噪差异”。本版不另加跨噪声泛化实验。

## 4. 输入处理：几何、对比度、低通与噪声

### 4.1 几何与空间单位

- 保留一个完整224×224画布送入单一网络。
- 左/中/右中心约为37/112/187，物体64×64；背景为RGB 0.5。
- 所有滤波参数明确注明是在**降采样前224像素物体坐标**还是最终64像素物体坐标定义。
- 224→64的采样比为3.5，新网格Nyquist频率折算到原网格为 `f_N=64/(2×224)=1/7 cycles/input-pixel`，两个空间方向分别满足。
- 所有输入使用固定、无随机增强的图像预处理；记录从原始图片到224物体的预处理与抗混叠设置，避免只修复最后一次缩小。

### 4.2 中央 target：必须先抗混叠低通，再降采样

拟采用以下顺序：

1. 原图确定性预处理为224×224物体图像，并进行ImageNet标准化。
2. clean 不加噪；noisy 在标准化224物体上加零均值高斯噪声，σ=0.5，保持与此前噪声定义一致。
3. 对两组均应用同一个二维可分离抗混叠低通滤波器。
4. 固定采样网格缩小到64×64，放置于画布中央。

**滤波器按频响规范设计，而不是把任意 GaussianBlur 称为严格满足Nyquist。** 拟使用对称窗化sinc/FIR：通带边缘 `0.8 f_N`，阻带起点 `f_N`，通带波动≤0.1 dB，阻带衰减≥60 dB；DC增益归一为1，边缘使用明确的反射扩展。采样相位统一对齐像素中心，不允许奇偶位置偏移。

实现阶段根据这些规范确定并保存核长度、系数、窗参数、频响和插值方式。可以保留额外的 antialias resize，但不能以其名称替代实际频响验证。有限核提供的是指定容差下的抗混叠，而不是理想无限阶带限的绝对保证。

**不在64×64图上重新加σ=0.5噪声，也不把滤波后噪声重新放大到0.5。** 低通会降低噪声方差，这是该处理链的一部分；必须报告最终物体内噪声SD、RMSE和信噪比，不能把参数0.5当作最终刺激噪声SD。该输入已不同于旧版，不能直接归因旧新版准确率变化于某一个因素。

### 4.3 左右 preview：更强平滑＋低对比度

左右两个物体、两段preview以及所有内容条件应用相同规则：

1. 对每个物体按通道空间均值缩减对比度：`x' = μ_channel + 0.5 × (x−μ_channel)`。这沿用旧工具函数的对比度定义，不是整体乘0.5。
2. 增加专用于外周预览的高斯平滑。拟固定 **σ_extra=1个最终物体像素，即降采样前σ=3.5像素**；核半径取至少4σ，归一化并采用反射边界。
3. 应用与中央target相同的抗混叠低通，再缩小到64×64。
4. 放入左右位置；不对整幅已合成画布进行模糊，以免把物体边缘与背景混在一起且引入位置依赖的有效对比度。

因此：**central = 抗混叠低通；parafoveal = 降对比度＋额外高斯平滑＋相同抗混叠低通**。外周有效频响应比中央更低通，不能让两者最后实际模糊程度相同。

额外σ的空间单位与旧半视野实现不同：这里恢复旧版的“高斯平滑＋对比度0.5”原则，不声称等价复制其旧几何下σ=1的最终视网膜尺度。上述σ为新协议的拟议固定值，不按分类正确率挑选。

### 4.4 输入验收

- 常量图：滤波/降采样保持均值，除预期边界外无非预期亮度变化。
- 正弦光栅/棋盘：在新Nyquist附近及以上检查衰减与输出混叠；记录频响与实测误差。
- 使用相同光栅确认preview的高频衰减强于central，不只依据肉眼。
- 对比度0.5公式在额外平滑之前检查；平滑之后的最终对比度可以进一步下降，应另外记录。
- 保存滤波核、归一化张量、全部preview画布及clean/noisy target，生成大尺寸物体crop供审查。
- 同一目标噪声种子的target hash须在12个条件间一致；clean与noisy仅目标噪声步骤不同。
- 不为显示而修改模型输入；显示RGB裁剪只用于图片预览并注明。

## 5. 灰屏与记忆状态

- 固定原共同灰屏方案：前馈初始化、Hebbian关闭、22步灰屏。先验证当前未变模型能复现原状态摘要，不按新目标成绩重选灰屏时长。
- 新版建议把五层 `rep、prd、grd、prediction_error` 的完整快照持久化，连同模型权重、dtype、软件版本及哈希保存；每个worker读入同一快照并深拷贝恢复。若无法复现，停止排查，不能继续混用状态。
- 每trial清零W；Hebbian-only与Joint在两段preview结束各提交一次更新，target阶段W冻结。
- Hebbian-only：每段preview和target恢复灰屏神经状态，W保留跨段更新。
- PCoder carry-only：W=0，延续preview神经状态进入target。
- Joint：保留W，同时延续preview神经状态。
- PCoder4/5注入；coeff=0.05、decay=0.5、inh=4、稀疏阈值0.9；FC动态Hebbian更新关闭。
- backbone、PCoder预训练权重和递归增益不重新训练；网络为eval模式。

## 6. 四个目标层的记录与历史指标兼容

固定层与旧模块对应：

| 规范名称 | 旧模块名称 | 数据 |
|---|---|---|
| fc2 | hebbian_2 | 模块输出向量及x_tmp |
| fc1 | hebbian_1 | 模块输出向量及x_tmp |
| conv5 | hebb_pcoder5 | 模块完整输出特征图及x_tmp |
| conv4 | hebb_pcoder4 | 模块完整输出特征图及x_tmp |

每trial、每target时间点记录四层。激活输出采用FP32；统计累加采用FP64或经验证的稳定FP32实现，不用低精度累加误差制造小幅sharpening。

**必须区分两个历史提取路径：** 旧 sharpening 将卷积特征图完整展平；近期 `_FeatureRecorder` 对卷积层做空间平均后存为通道向量。新版sharpening沿用完整展平定义，不直接拿GAP后的conv向量代替。FC2分类读出仍使用其4096维向量。

### 6.1 激活强度

- 用户所需的“层输出强度”：每张目标、每时间点的 `mean(output)`，并保存 `mean(abs(output))`、非零比例、max、25/50/75分位数。
- 为保持旧方案可追溯，另保存同样统计的 `x_tmp`；旧实现主激活指标是 `mean(x_tmp)`，不是笼统的 mean(abs(output))。
- 图表明确区分 `output_mean` 与 `legacy_x_tmp_mean`。如果实现验证表明二者相同，应提供数值验收记录，而非默认等同。
- 只有确认所有输出非负时，才可写 mean=mean absolute；不能据此省略验证。
- 输出相对different-category的绝对差和百分比变化。先计算条件组均值，再取 `100×(prime_mean/baseline_mean−1)`，与旧分析口径一致；baseline接近零则百分比记NA，不以任意ε生成巨大比值。

### 6.2 Sharpening：沿用既定几何指标

对完整展平特征 `x_i`，定义 `u_i=x_i/max(||x_i||₂, ε)`；零向量比例单独报告，不假装全零向量长度为1。类别使用四个任务大类。

| 指标 | 定义/解释 | 预期sharpening方向 |
|---|---|---|
| raw trace variance | 类内原始特征方差迹，旧定义为有偏总体方差 | 降低仅作诊断，可能只是幅度下降 |
| normalized trace variance | `E||u||² − ||E u||²`，按类别算后等权平均 | 降低 |
| within-class cosine | 同类不同样本的平均余弦相似度 | 升高 |
| normalized between scatter | 归一化类别质心相对整体质心的均方距离，类别等权 | 结合类内指标解释 |
| normalized Fisher ratio | normalized between scatter / mean normalized within scatter | 升高 |

within cosine使用 `(‖Σu_i‖²−Σ‖u_i‖²)/(n(n−1))`，沿用旧实现对零向量的处理；n<2时记NA。normalized trace与within cosine在单位向量条件下存在代数关联，不能作为两份独立证据累加。

相对同载体、同噪声、同时间点different-category，保留旧字段：`activation_effect_pct`（以legacy_x_tmp为历史对应）、`normalized_trace_effect_pct`、`within_cosine_delta_x1e3`、`normalized_fisher_effect_pct`。同时新增明确命名的output激活效果字段。

旧“complete sharpening”逻辑保留为描述性组合：激活下降、normalized trace下降、normalized Fisher上升同时成立。它不是独立显著性检验；单纯激活抑制不称为sharpening。若旧x_tmp和output的方向不一致，分别报告，不择优命名。

### 6.3 汇总单元

- noisy的sharpening先按每个固定噪声实现、每条件、每时刻计算，再等权平均三个噪声结果；不要把同图三噪声直接当作三个独立类别实例，抬高类内相似度。
- clean只计算一次。每概念两目标配额固定，四类等权。
- 全队列几何指标作为主描述，同时输出折内测试子集指标检查稳定性；不能以五折几何值的SD构造独立样本t检验。
- 当前仍是按四个任务大类定义的sharpening，不能与历史200类/概念级指标的绝对值直接比较。
- 在线统计仅保存类别总和不足以支持事后概念bootstrap。需保存每概念的可加总充分统计（n、Σx、Σx²、Σu、Σ||u||²），以及逐图激活量；这样以后才能保持概念簇重采样。无需为了读出保存所有完整conv特征图，但诊断样本应保存原图张量和全层输出。

## 7. t9固定读出：五折内训练一次，跨时间评估

### 7.1 主定义

每个数据集、每种target噪声水平、每折训练 **一个共同的t9分类器**：

1. 只使用该折训练目标的t9 FC2特征。
2. 12个载体×内容条件等权，类别/图像权重平衡；noisy三个版本各权重1/3。
3. StandardScaler只拟合训练折，LinearSVC固定C=1；二者均使用同一权重。
4. 同一个scaler和SVM冻结后，评估该折未见目标的12个条件与t0–t14。
5. 五折合起来每个目标恰好测试一次，保存OOF类别分数、标签、预测及fold id。

这会产生每个数据集/噪声水平五个t9读出器，而不是用全部目标拟合一个头后在同一批目标上测试。不同内容使用相同折内边界，更适合回答固定读出任务的priming效应。载体之间虽共同参与平衡训练，但不做彼此效果比较。

正式估计器为 StandardScaler+LinearSVC(C=1, dual=auto)，随机种子固定；沿用50,000/200,000迭代上限的仅收敛重试规则，不以成绩调C。输入先转FP32，防止保存特征的float16在标准化时溢出。

### 7.2 “平均结果”的明确口径

- 主图展示**五折指标算术平均**，满足统一CV汇报口径；同时提供五折原值及SD。
- Accuracy另给按测试目标数加权的OOF pooled accuracy，说明16/16/16/8/8的折大小导致其与等权fold mean可能不同。
- 折SD只表示划分间波动，不是独立重复实验的不确定性；不把SD/√5当严格标准误。
- 所有内容比较均先在同一折计算prime−different，再平均，不能拿不匹配折的均值作检验。
- 不根据CV曲线挑峰；t9读出在t≠9时刻属于时间泛化结果，需如此标注。

## 8. 逐时间点MVPA

- 使用同一五折；每条件、每时刻分别拟合 StandardScaler+LinearSVC(C=1)。
- 每次标准化、模型拟合只使用训练折；测试集不参与模型或参数选择。
- FC2为固定读出层；15时刻全部报告，无层/时间择优。
- 汇报五折平均accuracy与ROC-AUC，以及fold SD、逐折结果、OOF accuracy与分噪声结果。
- MVPA条件间的分类器可不同，描述的是各条件信息可解码性；t9共同边界描述固定分类器可利用性。二者不能视为同一估计量。
- 不重新加入跨载体对比或“联合协同”的MVPA检验。

## 9. AUC定义：不混淆分类曲线与时间曲线

用户所说AUC主解释为 **ROC-AUC**，每个时间点计算：

- 四类one-vs-rest：每一类用对应SVM decision score与二值标签算binary ROC-AUC，然后四类等权平均（macro OVR AUC）。
- 不用argmax预测标签算AUC，不要求把SVM分数强行softmax为概率。
- 每折独立计算AUC，再平均。**不直接混合来自不同折模型、尺度可能不同的原始margin计算一个pooled AUC。**
- 保存四类各自AUC；每折四类均有正/负样本，否则验收失败。
- Accuracy以百分数显示，差值单位pp；ROC-AUC以0–1显示，差值标ΔAUC。若乘100，明确标AUC points，不能混为准确率百分点。

另保存时间曲线的归一化梯形积分，命名 `temporal_integral_accuracy` / `temporal_integral_roc_auc`，与ROC-AUC严格区分。积分除以窗口长度14，其端点权重为半，**不等于15个时间点的算术平均**；仅作次级描述，不用来代替原定窗口均值。

## 10. 比较、窗口与统计解释

### 10.1 统一baseline

在每个dataset×target噪声×carrier×time×layer内部，分别计算：

1. exact − different category；
2. same concept − different category；
3. same category − different category。

分类accuracy、ROC-AUC、输出激活、legacy激活、sharpening均使用这套baseline。基线不跨载体、不跨噪声水平、不跨时间点。正文不做exact−same concept等额外假设检验。

### 10.2 固定展示与摘要

- 全部t0–t14。
- early t0–t4、middle t5–t9、late t10–t14、full t0–t14。
- 固定t9单点；不报告挑选出的“最佳时刻显著性”。
- clean/noisy各自完整呈现；可补充“各自priming效应的差值”描述噪声调制，但不把两个独立拟合分类器的原始准确率差解释成纯输入噪声因果效应。

### 10.3 第一阶段的推断边界

本计划的必做交付为完整CV指标、配对差值、折间波动和表征指标，不把五折当五个独立样本做t检验，也不对固定OOF预测直接作忽略分类器拟合不确定性的显著性宣称。

若后续需要正式宣称CV读出优势，应单独执行**包含完整标准化/分类器重新拟合**的概念簇重采样或有效置换流程，并事先登记端点和检验家族；本阶段不自动启动高成本的全时间MVPA重拟合置换。建议优先t9固定读出的exact−different单点t9：2数据集×2噪声×3载体=12个accuracy比较；ROC-AUC作为另行声明的次级家族，不在看到结果后选显著指标。其他内容、窗口、层的正式推断另行控制多重比较。

激活和sharpening的概念簇bootstrap无需拟合分类器，可作为本版必做区间：按大类分层重采样目标概念10,000次，保留概念内两图及全部配对条件/噪声，重新计算指标与baseline差值。区间注明为边际描述性95%区间，非同时区间；逐时刻CI不用于宣称全曲线显著。

## 11. 资源规模与输出结构

按64目标/数据集、12条件计算：

- clean：每数据集64×12=768个target序列。
- noisy：每数据集64×3×12=2,304个target序列。
- 两数据集合计 **6,144个target序列、92,160个target时间点**，另加preview与灰屏准备，开发验收另计。

- MVPA：2×2×12×15×5=**3,600次SVM拟合**，收敛重试另计。
- full-map sharpening只在target记录；不以conv GAP向量替换。正式执行前根据诊断样本估算显存、存储和耗时，不在计划中虚构完成时间。
