# 全因子矩阵与联动3D快照

本次只改变展示方式，复用已经完成的表征效应、概念bootstrap区间和CV内容差值，不重新拟合模型或执行新的假设检验。

交互总览在当前对话中显示。矩阵同时呈现36个数据集×噪声×载体×内容组合、4个目标层和15个时间点。点选单元格后，3D快照、四层轨迹、FC2 accuracy及ROC-AUC内容差值联动更新；也可用原生下拉框和时间滑块选择。

3D快照在一个数据集×噪声×载体内同时显示4层×3种priming内容。可切换柱体或点与区间、调整视角，使用局部Z轴观察细节，或切换全局Z轴保持不同组合之间的高度尺度一致。基线始终是同载体、同噪声、同时间点的different category；没有新增跨载体差值、排名或协同检验。

矩阵支持线性和对称对数颜色。对称对数为 `sign(x)·ln(1+|x|/c)`，c取该指标所有非零绝对效应的中位数。同一指标在全部层、时间及组合间共用颜色范围。颜色编码符号与大小，不编码显著性或“好坏”；不同指标有不同单位和量程。Raw trace variance仅作诊断，受幅度与维度影响。

单时点区间直接读取原始逐时点结果；early/middle/late/full窗口区间直接读取已有窗口bootstrap结果，不对逐时点区间端点求平均。读出显示五折均值，折SD在选中摘要中单列；不把它当作95%置信区间。交互中的数值保留6位有效数字，原CSV保留完整精度。
