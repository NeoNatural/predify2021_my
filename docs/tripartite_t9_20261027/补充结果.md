# 本轮三等分布局：t9 固定读出补充结果

2026-10-27。本分析使用本轮保存的 FC2 特征；未重跑网络、刺激序列或 MVPA。确认集此前已经查看，因此为事后补充分析，不是新的独立确认。

## 核心结果

本轮 t9 读出没有确认稳定的联合记忆优势。16 项载体差异检验（两数据集×四对比×t9/全程两个端点）的 Holm p 均为 1.0000。未通过检验不能解释为条件等价。

联合−Hebbian-only 的全程差值：ImageNet −2.85 pp，THINGS +0.07 pp；原跨时间共同读出均为 −7.01 pp 且通过其原预定校正。故原结论应限定于原共同读出，不能直接推广到任意固定分类器。原预定结果仍保留，新增分析不替换它。

## 训练与平衡规则

使用原 train 集80图、40概念，仅读取 t9；四类动物、服饰、食物、车辆。训练一个 StandardScaler+LinearSVC(C=1)，冻结后评估同一确认集64图、32概念、3噪声、28条件和15时刻。训练与确认目标概念互斥。未用开发或确认成绩选择参数。

每图每噪声纳入全部5种内容。无记忆权重15；每种PCoder内容权重3；每种Hebbian/联合的内容×强度权重1.5。6,240个不同训练行、权重总量14,400；每图180，四载体各45。每图×条件权重与原跨时间轮转采样逐项相同，StandardScaler及SVM均使用权重。这样保持原损失总量，避免因训练行数下降而改变有效正则化规模；时间状态的多样性仍不同。

两分类器均在50,000次迭代上限内收敛：ImageNet 13次，THINGS 11次。

## 数值与记录完整性

保存的特征为float16。首次补充推断直接送入标准化器导致溢出，尚未保存补充成绩；随后按原共同读出的数值规则先转float32再推断。未截断特征、改动标准化参数或重新选择模型。原分析脚本和已训练头保留；转换包装器及原因记录在 execution_precision.json。

原 head.pckl、freeze.json 和 manifest.json 的哈希在补充前后相同。新增头和预测独立保存在 Hebbian-CNN/Log/tripartite_t9_20261027；原冻结研究不修改。

## 结论与后续优先级

1. t9固定读出与跨时间共同读出共同作为后续主要分析；报告同一时刻对比及完整曲线，避免挑峰。
2. 原共同读出下联合低于Hebbian-only的发现具有读出依赖性；当前t9补充不确认该差异，也不确认联合优势。
3. MVPA保留为次级诊断，暂不优先投入扩展MVPA或复杂置换。曲线波动本身不证明方法失效；当前尚未量化完整重新拟合的不确定性。
4. 优先在开发数据拆分Hebbian更新强度、抑制以及PCoder状态延续的贡献。新机制需冻结方案并使用新确认数据。
