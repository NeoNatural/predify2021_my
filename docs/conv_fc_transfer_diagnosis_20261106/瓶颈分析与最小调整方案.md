# 卷积移植的瓶颈分析与最小调整方案

2026-11-06。本轮仅重新统计已完成实验的CSV、读取已有模型元数据并分析公式；没有拟合模型、运行新条件、实现新算子或执行参数搜索。原实验文件保持不变，输入哈希见analysis_audit.json。

## 结论先行

瓶颈不是临时记忆没有建立，也不是单纯把作用强度调大就能解决。现有证据指向三件事：**匹配信号对重复身份的区分不稳定；增益方向没有稳定服务于类别几何；局部Conv4的减活动在下游被显著削弱，个别条件发生反向变化。**

full相对pool的早期FC2 Fisher在8/8组合中更低，但两条分支的失效表现不同：原通道主要是类间距离收缩超过类内收紧收益；SAE主要是相对pool增加了类内散度。它们不能都归因成“抑制太弱”，也不能归因成已证实的迭代爆炸或某条反馈连接的补偿。

优先建议：先进行同W、同输入、同阈值的局部配对诊断，再把增益移到抑制之后，以抑制后响应作加权中心，使同一局部比较中full与pool严格同总量。缩小ε，有限上调λ；先确认匹配特异性再做强度搜索。暂不扩大SAE容量，不改变临时写入、FC Hebbian关闭和target冻结约束。

## 2. 为什么没有稳定suppression：有共同抑制，不等于有足够的重复特异抑制

当前阈值为τ=λ(μ+σ)κ/(κ+κ₀)。八个组合中，全空间平均κ的早期E/D差有四个为负，说明这个汇总匹配指标没有稳定把Exact排在Different前面。但这不能推出中央target位置也没有有效信息，因为现有trace没有保存逐位置κ。

一个具体例子是THINGS原通道rep4：Exact平均κ低约1.34%，阈值却高约4.96%。因此，阈值的历史差异不能直接被解释成记忆识别能力；μ+σ的差异、κ与活动的空间协变也在参与。只有全空间均值，尚不能把各项贡献严格拆开。

κ均值与各自训练κ₀的比约0.95–1.04。以典型值作量级估算，κ/(κ+κ₀)处于约1/2附近，不是接近1的深饱和区；其相对κ变化的弹性约为1/2。这是均值量级估算，并非逐位置门函数的实测平均。继续降低κ₀可能增强共同抑制，却进一步压低对κ差异的敏感度，不能作为默认修复。

原无Hebbian PCoder已经带有早期Exact增强：按本轮逐target比值口径，Conv4的suppression为ImageNet−0.243%、THINGS−0.074%。原通道rep4将其移到−0.133%／+0.005%，方向有改善，但尚未稳定反转；八个full组合的早期Conv4概念块区间仍全部跨零。局部1%–2%的减活动并不等于1%–2%的Exact−Different差异。

代码层面的潜在原因是：记忆用整张preview的非中心化正共激活、空间平均和共享通道/偏移权重。重复物体、其他物体和共同画布成分没有显式分离；左右preview与中央target还有位置和外观变化。这使共同成分稀释匹配特异性成为合理假说，但现有汇总数据不能把原因坐实为背景或空间迁移，需要预先固定ROI及空值对照后验证。

## 3. full为何不如pool：截零、方向与闭环耦合须分开

### 3.1 零均值只在截零前成立

当前更新为y=[x⊙(1+m)−τ]₊，且Σ通道xm≈0。但一般并没有Σy=Σ[x−τ]₊。

例如x=(10,1)、m=(.003,−.03)、τ=2时，Σxm=0；pool输出(8,0)，full输出(8.03,0)。负调制落在已经被截掉的弱响应上，没有形成实际减量；强单元的正调制保留下来。这个例子说明机制可能性，不是对实际单元分布的测量。

直接分支在第一侧向步就把约56%的正编码支持降到约15%–16%，后续增益读取又用当前正编码门。这使“保留强响应上的增加、弱响应上的减少不可见”值得优先检验。实际正负调制保留量未保存，不能仅凭现有RMS宣称已经量化了这项贡献。

### 3.2 full不是因为末步阈值更低才失去优势

按配对trial统计，Exact侧向第5步full的阈值反而比pool高约0.48%–1.23%。但full的早期Conv4 suppression均略弱，FC2 Fisher也8/8更低。因此“full只是抑制招募不足”不是充分解释；增益方向、截零和传播至少同样需要检查。

### 3.3 五步内存在耦合，但没有爆炸证据

Exact的第1→5步：原通道full的κ约下降0.18%–0.27%，SAE full约上升0.53%–0.83%。阈值变化约−0.35%至+0.52%，full非零密度的后续变化很小。主要支持集变化在第一步已发生，不能把本轮失效概括为“不收敛”或κ爆炸。

pool的κ/阈值通常下降更多；full改变了后续查询和池强度。但full/pool在第二段preview就可能产生不同源活动和W₂，target输入和PCoder状态也不同。因此当前8/8差异是两套闭环机制的差异，不能全归于固定W下的一次局部增益。

### 3.4 类别几何显示两条不同的方向瓶颈

比较相同Exact历史、早期FC2 full与pool：

| 分支 | 类内散度变化 | 类间散度变化 | 判断 |
| --- | --- | --- | --- |
| 原通道，四个数据／来源组合 | 均下降，约0.15%–0.67% | 均下降，约0.39%–0.78%，损失超过类内收紧收益 | 更集中并未换来更好的类别分离 |
| SAE，四个组合 | 均上升，约0.04%–0.12% | 小幅上升或下降 | 局部回投增加了类别内变异，未稳定增加类间分离 |

窗口Fisher是各时间步Fisher的平均，不等于窗口平均Between/Within之比；上表用于说明方向，精确Fisher变化见geometry_full_vs_controls.csv。

q来源于冻结记忆的共激活能量梯度，经tanh、中心化和乘性控制后作用于原表征。它没有类别监督目标；让当前响应更匹配preview，并不保证同类不同图片更接近或不同类更远。这是比“再加大ε”更根本的方向问题。

## 4. 原通道与SAE：不能把不同图坐标当成单一压缩消融

SAE的原始q回投被限制在固定512→32投影子空间中；随后tanh、加权中心化和乘x是非线性操作，所以不能进一步声称最终扰动也只有秩32。训练投影坐标FVU约6.74%／7.36%，只说明辅助拟合质量，不证明原512维类别方向被保留，也不是隔离概念的泛化验收。

SAE读取的活跃latent比例在五步中约30%／32%，相当稳定；原通道正编码门则从约56%缩到15%–16%。两种门控作用在不同坐标上，不能直接比较活跃比例或把SAE较低RMS当作更准确的选择性。

图结构也有差异。rep4来源的实际柱间候选密度，原通道约0.069%／0.073%，SAE约1.93%／2.08%；相同top32不表示相同稀疏比例。prd5来源的柱间最大行和，原通道约.12，SAE约.20–.27，后者更强。训练c/κ₀定标能调整平均读取尺度，不能消除空间、通道和连接分布差异。

因此，当前可以说SAE改变了增益坐标与传播行为；不能仅用THINGS的某项正Fisher变化认定压缩更好，也不能单凭原通道更稳认定SAE没有价值。首轮最小调整不扩大SAE、不改投影维数，避免同时改变方向、容量、图密度和强度。

## 5. 递归与下游传播：已经定位到哪一级，尚未定位到哪条连接

早期Exact相对同历史clip的均值变化如下，单位为百分比：

| 数据／组合 | Conv4输入 | Conv4输出 | Conv5 | FC1 | FC2 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ImageNet 原通道rep4 | −.181 | −1.572 | −.288 | −.310 | −.093 |
| ImageNet SAE rep4 | −.256 | −2.224 | −.280 | −.472 | −.045 |
| THINGS 原通道rep4 | −.174 | −1.483 | −.246 | −.304 | −.082 |
| THINGS SAE rep4 | −.241 | −2.171 | −.107 | −.458 | +.061 |
| ImageNet SAE prd5 | −.179 | −1.778 | −.067 | −.325 | +.065 |
| THINGS SAE prd5 | −.190 | −1.871 | −.001 | −.309 | +.114 |

Conv4输入本身略降，不能说PCoder4的反馈已经把局部均值补回。明确的衰减与反向变化发生在Conv4之后的实际传播中：有符号前馈权重、bias、ReLU、池化和PCoder5循环共同参与。现有统计没有将这些路径分别冻结，不能把反向变化唯一归于反馈补偿或某条FC连接。

同时，局部抑制在每个网络步都作用于新的递归输入。五次侧向更新不是五次独立证据，15个target网络步也不是独立样本。需要在共用preview终点状态下分支重放，才能区分PCoder历史、临时W和下游传播。

## 6. 最小调整：先抑制，再在抑制后预算内重分配

保留trial清零、两段preview写入、W₂冻结、柱内充分候选、柱间稀疏、FC Hebbian关闭及原前馈权重。每个网络步仍使用当下非负原Conv4输入x。

先在该网络步初始x上计算κₓ和μₓ、σₓ，并在该步五次侧向迭代中冻结阈值：

\[
\tau_x=\lambda(\mu_x+\sigma_x)F(x,W),\qquad b=[x-\tau_x]_+.
\]

然后令r₀=b，按当前r读取同一冻结W得到q、u=tanh(q/c)，只重分配b：

\[
\bar u_b=\frac{\sum_c b_cu_c}{\max(\sum_cb_c,\delta)},\qquad
r_{k+1}=b\,[1+\varepsilon(u_k-\bar u_b)].
\]

取ε<.5，则增益为正，Σ通道r=Σ通道b，b=0的单元保持0。无需再对这一正乘积截零。**同一W和x条件下，full与pool的局部总量、被阈值关闭的支持集严格一致**，可更直接判断内容重分配是否改善类别几何。它不固定活动单元数量，也不对响应排序；活动稀疏由阈值控制。

不同闭环条件仍可能产生不同preview2、W₂和下一网络步x，因此不能把该局部恒等性扩展成“两个完整递归序列全程等均值”。仍保留原有逐网络步等均值缩放对照。

这个改动只解决截零后预算和阈值耦合问题，不保证记忆方向变成类别最优方向。若ε=0一直更好，应接受仅抑制更优的结果，停止放大增益。

## 7. 搜索前的最小诊断，不与搜索做笛卡尔积

以下均为待执行提案：

1. 每类取两个训练target（ImageNet8、THINGS10），保存真实preview末态W₂、PCoder状态和target输入。先只做rep4来源的原通道/SAE两分支。
2. 在同一份W、x和阈值上比较当前pool、当前full、新的抑制后重分配。记录正/负调制量经ReLU后的保留、实际活动加权RMS、类内/类间几何及下游实际FC；这一步才量化截零机制的贡献。
3. 预先固定中央target ROI，同时报告全图、ROI和按x加权的κ/F；不要看完结果再挑ROI。用相同W的一组固定打乱排列检查共同匹配底座，报告训练Exact/Different配对差及概念块区间。
4. 少量trial用同一W₂/preview末态，诊断W=0/W₂与灰屏/preview PCoder状态的2×2消融。再比较固定输入轨迹的局部重放和真实闭环，定位原PCoder历史与传播。它是carrier诊断，不改变主实验的trial内流程。

若原F在有活动的位置仍不区分Exact/Different，先不放大λ。可以单独检验一个无需target学习的对比匹配：ν=[κ(x,W)−κ(x,Wπ)]₊，F=ν/(ν+ν₀)，ν₀只在训练折估计，Wπ仅作冻结空值参考。这仍可能失败；必须先确认训练侧特异性改善，才进入强度网格。不要同时把两个F版本放进大网格，也不默认对比匹配已经有效。

## 8. 首轮6点、最多9点的小范围参数搜索（未执行）

匹配诊断通过后，固定F版本和抑制后重分配结构：

| 参数 | 范围 |
| --- | --- |
| ε | 0、.005、.01 |
| λ | 首轮.03、.06；满足下述条件时才补.09 |
| 侧向步数 | 固定5，不以收敛为验收条件 |
| 权重来源 | 主搜索只用rep4；prd5保留旧点作诊断，赢家才补单点复核 |
| 分支 | 原通道、轻量SAE；两数据集共用同一参数网格 |
| 其他 | 写入、衰减、top32、空间池、前馈权重保持不变 |

首轮共6个参数点；只有训练验证的匹配方向正确、功能门槛通过而重复差异幅度仍不足时，才补λ=.09的3点，合计最多9点。不是9×所有结构版本。ε=0是正式候选；旧ε=.03/λ=.03作为历史锚点，不能删掉不利对照。不设“各条件至少下降1%”这类会迫使选强增益的工程下限。pool已包含在ε=0行，不为每个非零ε重复运行；同均值缩放及固定权重打乱只对进入最终复核的少数点补齐。主搜索不再增加容量、投影维度、k、κ₀或步数网格。

训练folds1–3内部按概念做三折小批量验证，内验证每类至少两个概念、每概念两图，避免把单个概念的图像内聚当作大类sharpening。每折SAE、投影中心/尺度、q/κ定标和vanilla固定SVM都仅由内训练部分拟合；现有已看过三折的SAE/SVM不能当作该内验证的无泄漏模型。固定投影随机种子和原网络checkpoint可以共用。主网格必须看真实闭环结果，不能只凭局部缓存筛查后声称网络已通过。开发fold4不再用于选点，fold0继续保留。

选点按以下顺序，允许没有赢家：

- 功能门槛：建议预先固定为FC1、FC2的内验证平均BA损失≤1个百分点、宏AUC损失≤.01，并公开最差折。当前部分平均margin为负，不能使用“保留95%”的比值。采用同头margin差，并按内训练参考margin标准差归一化，不低于−.05个训练标准差。AUC和margin先在各自内折同一头下计算再汇总，不将未经校准的跨头分数直接拼接。
- 活动/历史门槛：报告实际Conv4及下游活动，区分对同历史clip的降低、Exact−Different、Exact−none；要求重复差异相对原PCoder基线向目标方向移动，而不是只得到共同抑制。若声称稳定suppression，应有跨验证折/概念的一致方向，不能凭单个近零正号。
- 几何排序：考察同历史clip的Fisher与Within/Between，再要求非零ε在等均值条件下优于对应pool/scale，且非零向量/类别结构不塌缩。重复特异几何需另报告Exact−Different及其相对无Hebbian的差值之差，不能用普通侧向处理收益替代。
- 只有训练内验证选定的少数点才进入完整闭环复核。必要时为赢家补训练侧三历史共享重拟合SVM，固定头和共享头分别报告，不分别为Exact/Different挑分类器；不把重拟合头margin绝对值与固定头直接比较。

若所有非零ε都不如pool，冻结ε=0只能作为诊断/更稳对照，不能称完整增益通过。若加大λ只有均值下降而没有重复差异改善，停止强度扩展，回到匹配表征和空间对应诊断。

SAE与原通道的连接比例仍是结构混杂。若SAE继续失利，可另补一个latent柱间k=4的密度预算对照（与512通道k32的候选比例一致）；这是后续单点，不纳入首轮6点或条件扩展后的9点，也不把该控制等同于完全匹配有效边数或权重分布。
