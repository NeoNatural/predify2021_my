# Hebb-FC 接入预测编码模型：小批量测试

两数据集分别用本轮正式队列的干净中央目标画布重新拟合FC1/FC2连接和RMS尺度；ImageNet 320图、THINGS 400图。仅复用独立FC研究的算法与超参数，未加载该研究的训练权重和划分。评估使用每个类别1个开发概念、每概念2张图；训练概念与开发目标/preview角色隔离。

FC1为corr/k128，FC2为corr/k32，侧向增益0.75，每次网络前向各做5次更新；分别计算排序配额、群体均值、均值＋标准差、动态反馈，并保留关闭FC、仅抑制、均值匹配缩放对照。FC状态每个网络时间步重新初始化；固定连接不在预览或目标期间更新。预览仍为2+2步，目标t0–t14。

小样本覆盖三种原有记忆模式、clean和一个固定噪声实现、exact/同概念/同类/异类；THINGS植物开发队列只有一个概念，因此其同类不同概念条件省略，包含该条件的THINGS指标只涵盖其余四类。

真实预测编码网络共运行ImageNet 192条、THINGS 228条基线轨迹。FC在所有PCoder之后，没有到PCoder的反馈；本测试使用保存的每步FC1输入重放全部FC设定。每种设定均用真实模型中FC1/FC2钩子另行核对：代表性轨迹在目标阶段的PCoder4/5状态、目标开始时预览权重及FC输出逐位一致，目标期间权重保持冻结。各规则的优化实现另外用每层四个样本验证逐位一致。重放不声称额外生成了新的PCoder轨迹。
