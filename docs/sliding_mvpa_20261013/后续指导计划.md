# 当前指导计划：噪声下的逐时间点 MVPA 与记忆机制

更新：2026-10-13，依据用户指示。本计划替代此前以计算效率为导向的后续建议。

## 研究目标

研究噪声输入下，预览记忆如何影响目标出现后的类别可解码性、表征变化及时间进程。主要按目标时间点 t0–t14 对齐条件，不将主干调用次数、等计算预算、FLOPs、运行延迟或加速比作为目标、主要端点或继续实验的门槛。历史等预算结果保留为既有实验记录，不再指导后续取舍。

## 已完成的噪声实验

ImageNet 与 THINGS 的 sliding estimator 均使用 `predify_noise`、`level=0.5` 的目标图，每张目标有 3 个噪声实现。噪声在物体合成到小对象画布之前加入；预览使用原图，属于清晰预览后识别受损目标的设计。当前结果不是 clean 条件，噪声参数也不能直接当作最终画布的像素标准差。

两数据集均覆盖 7 条件、15 时间点、概念分组的 5 折 CV，共 1,050 次拟合。保持各条件和时间共用折划分，所有噪声版本随概念分组，标准化只拟合训练折。详见《逐时间点MVPA结果.md》。

## 后续优先级

1. **噪声下的条件内可解码性。** 将 sliding estimator 作为传统 MVPA 的主要分析，完整报告所有时间点。同图分别与同概念不同图、同大类不同概念、异类、中性以及两种无记忆初始化比较，区分精确重复、语义一致性和一般状态效应。
2. **时间曲线的统计推断。** 在固定划分和完整重新拟合的流程内设计标签置换，控制时间点和预定条件比较的多重检验。不能把 CV 折或噪声版本当独立实验样本；不通过测试曲线挑选最优时间窗口。
3. **读出依赖与表征机制。** 保留 matched_t9、pooled 作为互补分析，比较早期可解码性与固定决策边界可利用性。分析类间/类内结构、目标类 margin、错误转移及状态位移，避免将激活降低直接解释为识别改善。匹配读出训练规模、权重和正则化后再归因时间覆盖效应。
4. **当前噪声范围。** 用户已选择保留 noise = 0.5，完善逐时间点分析。本轮不增加 clean 或其他噪声强度，分别报告三个噪声实现的配对差值与方向一致性。

跨时间点泛化继续暂缓。当前已查看数据的重分析标为探索性；后续确认类别信息或内容效应时，另行预留独立图片，而不以计算效率是否改善决定研究价值。
