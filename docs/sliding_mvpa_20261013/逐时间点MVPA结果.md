# Time sliding estimator 补充结果

2026-10-13。ImageNet 与 THINGS 均已完成：每个条件、每个时间点独立训练并在同一时间点交叉验证。共 2 数据集 × 7 条件 × 15 时间点 × 5 折 = **1,050 次 SVM 拟合**，全部收敛。本轮没有计算跨时间泛化矩阵。

## 方法与解释目标

**本报告全部目标均有噪声：predify_noise，level=0.5，每图三个噪声实现，预览为清晰原图。** 噪声在物体合成画布之前加入，不能将 0.5 直接解释为最终画布标准差。

使用最新实验已保存的 FC2 特征（4,096 维），复用原测试图片：ImageNet 100 张、87 个 synset、5 大类；THINGS 80 张、80 概念、4 大类。每图 3 个噪声版本，每个条件分别训练。没有重新运行神经网络或改动原冻结分类器。

按概念分组、按大类平衡进行 5 折交叉验证，所有条件和时间点共用同一划分。同一概念的图片及其 3 个噪声版本不跨折。ImageNet 验证折分别含 19、22、19、20、20 张图片，训练折为剩余图片；THINGS 每折 16 张验证、64 张训练。ImageNet 植物概念仅 7 个，优先保证概念隔离及每折类别覆盖，不能同时做到每折图片数严格相等。

每个训练折独立拟合 StandardScaler + LinearSVC(C=1)，然后预测该折验证数据的同一时间点。每条观测每个时间点恰有一次折外预测。整体准确率来自全部 OOF 预测汇总，不是对大小不同的折简单平均。完整队列的大类数量平衡，因此整体 accuracy 与 balanced accuracy 一致。

这里采用与传统 sliding estimator 相同的“每个时间点一个 estimator”流程，使用 scikit-learn 实现，未安装额外 MNE 依赖。仅有 train t / test t 对角线，未执行 train t / test t′。方案和划分在拟合前固定，没有选择最佳 C、最佳折或最佳时间窗口。

**它检验条件内的类别可解码性，允许各条件拥有不同的分类边界；matched_t9 和 pooled 则检验固定边界的可利用性。** 新 CV 的训练图片数量、概念隔离和条件适配均与旧读出不同，跨读出差异不能唯一归因于时间点训练。

## 结论解读

**1. 逐时间点 MVPA 补出了冻结读出没有充分反映的早期可解码性。** THINGS 同图 t1 的 sliding CV 为 57.08%，matched_t9 为 32.50%，pooled 为 36.25%。这是重要的测量差异，支持继续区分“存在可提取的类别信息”和“固定边界能否利用它”。不过三者训练规模和条件适配也不同，不能把 +20.83 pp 全部解释为纯粹时间读出失配。

**2. 前馈初始化仍是必要基线。** sliding CV 下，ImageNet t0 前馈无记忆为 45.33%，随机为 27.67%；THINGS 分别为 67.08% 和 37.92%。逐时间点重新训练并没有消除初始化相关的早期差异。此处按目标出现后的相同时间点比较初始化相关的可解码性。

**3. 同图内容效应依赖数据集和时间，尚不能称为稳定精确重复优势。** THINGS t1 同图 57.08%、异类 38.75%，相差 +18.33 pp；但同大类为 57.50%，前馈无记忆为 64.58%。ImageNet t3 同图 43.33%，低于异类 48.00% 和同大类 47.67%。这些是描述性差异，不是经过时间多重比较控制的显著效应。

**4. 晚期多数条件接近，但不能据相近准确率宣称表征完全相同。** ImageNet t14 各条件约 47%，THINGS 约 64%。两数据集的任务类别数、图片组成及训练池不同，不能通过绝对准确率断言 THINGS 更容易。

**5. 后续解释以目标时间点为准。** 按用户最新研究目标，不再以计算预算、运行速度或效率收益评价这些结果。重点是噪声下的类别信息如何随时间变化，以及同图效应能否区别于语义一致性和一般预热。详见《后续指导计划.md》和《噪声条件逐时间点诊断.md》。

## 统计边界

当前测试集已经在先前工作中查看过，所以本轮属于探索性重分析，不是新的独立确认。图片作为外层实验单元，噪声重复不能当作新增独立样本。概念分组只约束读出训练/验证，不意味着预训练主干未见这些概念。

5 个 CV 模型的训练集重叠，OOF 误差也不独立。故本轮没有把折当作 5 个独立重复做 t 检验，也没有直接复用固定读出的 bootstrap/sign-flip 生成显著性结论。逐折和逐噪声数据均已保存；图中的机会水平只是参考线，不代表上方时间点已经通过显著性检验。如需正式曲线推断，应在独立方案中加入完整重新拟合的标签置换，并控制条件及时间上的多重比较。

本轮不计算跨时间泛化、不筛选后续参数，也不修改 slides 或旧报告的确认结论。
