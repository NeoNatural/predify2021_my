# FC1增益0.75：k32/k128的SVM与真正串联评估

本轮只改变独立侧向实验的FC1候选：正则化正相关、互为top32或top128、增益0.75、自适应hard门控、活动预算1.0。FC2固定为corr/k32、增益0.75、hard、活动预算1.0。除法强度2、更新混合系数0.5。原始VGG16、预训练权重、vanilla缓存和前轮结果均不改动。

流程：FC1侧向指定步数 → 原始冻结FC1→FC2仿射权重+bias+ReLU → FC2侧向指定步数。无反向反馈。

## 固定比较

两套vanilla数据、原五折概念隔离。FC1/FC2同步1、5、20步，5步作为主要截面，另外两档只作敏感性分析，不按测试结果或不动点筛选。

每种FC1图固定23个条件：vanilla；仅FC1、仅FC2各1/5/20步；真实串联各1/5/20步；5步FC1缩放+FC2 Hebbian、FC1 Hebbian+FC2缩放、双层缩放；双层仅抑制；仅FC1抑制、仅FC2抑制；仅FC1缩放。串联与缩放组合同时报告frozen/matched两种FC2口径。

- frozen：沿用vanilla训练FC2估计的侧向连接及尺度。
- matched：仅由本条件实际进入FC2的训练表征重估连接和尺度。
- FC1缩放逐图匹配同图、增益0.75、hard5的FC1均值。
- FC2及双层缩放逐图匹配同图、同FC2口径、真实hard-hard5的最终FC2均值。

FC1缩放对照的FC2仍使用同样规则与参数；matched时按其自身训练输入校准，frozen时共用同一个vanilla FC2侧向模型。两种口径都保留，避免将统计校准全部误归因于Hebbian连接。

## 评价

分别统计FC1相对vanilla FC1、前馈FC2输入相对vanilla FC2、最终FC2相对vanilla FC2、FC2局部处理相对实际输入。报告实际均值、归一化W/B/Fisher、原始几何、活动支持/弱响应/招募、有效维度、分大类激活和召回。SVM统一为训练折内加权StandardScaler+LinearSVC(C=1, dual=auto, max_iter=30000, random_state=20261028)，类别/概念权重与前轮一致，保留输入幅度。SVM只作功能检查，sharpening仍是主目标。

相同特征复用相同SVM；图相关特征必须分别拟合。既有vanilla、FC2-only和仅抑制SVM复用并核对逐图分数。FC1本层重放与前轮全网格的同折同参数结果核对。补充原始冻结1000类head的ImageNet兼容性指标，不将其与大类SVM混同。

与上一轮FC1增益0.25/k128作同折参照；不把本轮探索结果称为独立确认，不因SVM准确率不提高而否定几何sharpening。保留完整表征、模型、分数、训练索引、协议及哈希，检查原模型与缓存未变。
