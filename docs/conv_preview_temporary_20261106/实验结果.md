# Preview 临时卷积 Hebbian 修正实验

已完成两数据集 16/20 个开发目标，7 组（六组机制＋clip 校准基线），clean/noisy × exact/different-category，共 1008 条真实递归序列。每条为 2+2 preview 和 15 步 target。旧固定图结果没有复用。

每 trial 权重清零；两段 endpoint 各写一次，A₂=0.25H₁+0.5H₂；第二段 preview 使用第一段权重。target 既不学习也不衰减。所有序列的重置、写入数、冻结哈希、clean/noisy 的 preview 权重一致检查均通过。旧卷积与 FC Hebbian 均关闭，PCoder 状态在 trial 内延续。

## 结论

本轮确实测试了 preview 临时 Hebbian，而不是旧训练集固定图。576 条启用记忆的序列共完成 1152 次 preview 写入；其余 432 条对照序列权重恒为零。两数据集六组的真实模型 Exact→Different→Exact 检查均通过，重复的 Exact 全部特征逐位一致，非零记忆的最终哈希随 preview 身份改变。五项单元测试验证了累积式、偏移外积、稀疏互选、冻结，以及紧凑保存与完整图几何的等价性。

1. **当前参数没有建立跨数据集稳定的 repetition suppression。** 早期 t0–4，Conv4 的 Exact/Different 响应差在全部四格（两数据集×两噪声）均为正；加入临时 Hebbian 的四组范围为 +0.133% 至 +0.562%。FC2 早期同样均为正。概念成块 bootstrap 的早期 Conv4 原始 priming 区间均跨零，不能认定这些微小正差为可靠 enhancement，更不能解释为 suppression。
2. **rep4 乘性记忆主要增加了重复响应。** 相对乘性 none，其早期 Conv4 priming 原始差值之差在四格均为正，描述性 bootstrap 区间也均为正；时间曲线上该组的 Conv4/FC2 正差延续到后期。这里证明了保留的临时痕迹能影响 target，但影响方向没有满足重复抑制目标。区间未作多重比较校正。
3. **prd5 门控有微小几何变化，尚无联合 sharpening 证据。** 相对 gate_none，早期 FC2 的类内散度 priming 差值在四格都小幅降低（约 5.9×10⁻⁵ 至 9.0×10⁻⁵），但 Fisher 的额外变化正负混合，priming 准确率的额外收益四格均为零。其 Exact 的类内散度仍高于 Different，因此不能称为已得到类别内聚的 repetition sharpening。
4. **一般活动稀疏化仍以无 Hebbian 门控最强。** 早期四格等权平均，相对 clip，gate_none 的 Conv4 平均活动下降 14.19%，非零密度下降 88.15%，固定头准确率下降 1.84 个百分点；gate_prd5/gate_rep4 的准确率分别下降 2.59/2.34 个百分点。乘性 prd5/rep4 分别下降 3.34/3.22 个百分点，均未守住无 Hebbian 对照的读出水平。这里的准确率差是描述性结果，不是独立验证集的显著性结论。
5. **不把来源差异等同于纯粹的语义优势。** 两类来源具有相同候选结构和 top32 预算，但实际有效边数不同。第二段后 prd5 的柱间边均值约 538–597 条，rep4 约 1399–1552 条；柱间最大行权重和均值分别约 .124–.127 与 .145–.151。归一化发生于未剪枝增量，剪枝后不再抬高权重，因此两者实际柱间总强度也不同。完整统计见 weight_statistics.csv。

晚期少数组合出现接近零的负响应差，最小约 −0.004%（Conv4）与 −0.006%（FC2），没有形成跨数据集一致的结论。此次未继续调参、未增加其他记忆/抑制机制，也未使用 fold0。结论仅限本方案、这些固定参数与现有小开发集，不是否定所有 preview 临时 Hebbian 方案。

## 范围与核查

本轮是相同开发集上的机制修正小实验，没有独立测试结论。每数据集只有 8/10 个开发概念。paired_concept_bootstrap.csv 提供按概念成块的配对 95% bootstrap 区间；时间步和噪声不作为独立重复，未进行多重比较校正，区间用于描述不确定性。

完整 early/middle/late、逐步几何、读出一致率与余弦、权重审计分别见同目录 CSV。卷积几何由完整特征图的双精度单位范数 Gram 计算，未用空间池化替代；不保存原始卷积图，因此不能事后进行逐单元调谐分析。FC1/FC2 完整特征仍在 E 盘。
