# Preview 临时卷积 Hebbian：修正实验方案（2026-11-06）

本轮重新检验当前 preview 所形成的 trial 内临时权重，不使用训练集固定连接。旧卷积实验的机制和结果独立保留。本轮沿用旧开发集，仅用于机制诊断，不把重复使用的开发集称为独立验证集。模型、反馈权重均冻结；FC Hebbian 和旧卷积 Hebbian 都关闭。

## 对照与固定参数

六组为 gate/multiply × none/rep4/prd5，全部干预 rep4，另加 clip（仅非负截断）校准基线。none 保留与同版本完全相同的抑制与活动计算，权重恒为零；它仍可有 PCoder 状态引起的 priming。

沿用 γ=.25、柱间混合比例 ρ=1/3、λ=.5、活动混合 α=.5、每个网络时间步 K=3 次侧向活动迭代；gate 的 a=.25、b=.1。multiply 的 drive=x[1+γu/(1+u)]；gate 的 drive=x+γu，再以 aμ+bσ 阈值门控；两版均使用相同局部除性抑制。每步都以当前输入 x 作为固定驱动，活动 r 在该步内迭代，不额外保存抑制池。

应用尺度只读取旧训练集 rep4 的 RMS 标量（ImageNet 0.8745635748，THINGS 0.8318948150）及其来源元数据，不读取旧 graph.pt 中任何矩阵。不同权重来源都使用同一 rep4 应用尺度。

## 每 trial 的状态生命周期

每个 case、target、preview identity、noise 的组合都视为独立序列。开始时将新临时权重、其未剪枝累积痕迹、旧 Hebbian 的 boost_weight 和 pending state 清零，并将全部 PCoder 恢复到同一已有灰屏快照。没有上一 trial 的权重或 PCoder 状态传递。

1. Preview 1：运行两步；开始权重为零，第一段只承受本组的基础抑制/门控。两步结束后，取最后一步的实际 rep4 或同一步 PCoder5 生成的 prd5，提交一次更新，得到 W₁。
2. Preview 2：保留 PCoder 状态，运行两步，期间都使用 W₁；不在每步重复写入。结束后取第二段最后一步活动，衰减累积一次得到 W₂。
3. Target：保留两段 preview 结束时的全部 PCoder 状态，运行 t0–14；只使用 W₂，不提交更新，也不衰减。target 不参与权重、连接选择或尺度估计。噪声仅加入 target，因此同 case/identity/target 的 clean 和 noisy 序列应产生完全一致的 preview 权重。
4. 下一序列重新清零。

这是 PCoder 状态与临时 Hebbian 同时保留的对照，不是清除 PCoder 后的纯 Hebbian 记忆消融。rep4 来源使用实际受调制的 endpoint；prd5 来源使用原 PCoder5 预测模块在同一步生成的 endpoint。prd5 并不直接调制 prd5 或 rep5。

## 临时连接如何形成、累积和稀疏化

每段 endpoint 独立计算 z=ReLU(activity)/RMS(ReLU(activity))。按空间位置平均 z 的外积，得到同位置所有通道对的 H₀，并去掉自连接；对八个相邻位置偏移分别计算有效重叠区的外积，乘 exp(-||δ||²/2)，得到 Hᴸ。全空间共享通道/偏移权重，不保存绝对位置绑定。

H₀ 和 Hᴸ 分别除以各自全局最大行权重和，使两类增量最大行和为 1（全零活动保持全零）。这是当前 preview 的正共激活，不是跨训练图片的中心化相关。

未剪枝痕迹均按 Aⱼ=0.5Aⱼ₋₁+0.5Hⱼ 累积。因此 A₁=0.5H₁，A₂=0.25H₁+0.5H₂。记忆衰减 .5 和写入系数 .5 在看结果前固定；这种有界尺度沿用临时 FC 记忆的两段累积形式，并不声称数值上复现旧未归一化的 coeff=.05 模块。

柱内保留全部非自连接候选，不进行 top-k；不共激活的权重自然为零。“充分连接”指候选结构充分，不强行给零共激活单元加正权重。柱间在每次提交后，依据当时的累积痕迹，从所有通道×八偏移候选中做 mutual top32，互选后每个目标通道最多 32 条柱间边，保持反向对称。第一次没选中的边仍保留在未剪枝痕迹中，第二次按两段共同痕迹重新选择；target 阶段不再改变选择。

侧向驱动 u=(1-ρ)Conv1×1(r,W₀)+ρConv3×3(r,Wᴸ)。空间边界使用零填充，抑制池按有效邻居数归一化。不同来源具有相同候选结构、预算和增量归一化规则；有效正边数仍须实际报告，不预设相同。

## 样本、评价与保存

ImageNet/THINGS 沿用 fold4 每类两个概念、每概念两图，共 16/20 个目标；身份为 exact/different-category，target 为 clean/seed2921 noisy。每序列为 2+2+15 网络步，总计 1008 序列。目标与 preview 生成方法、位置、低通与对比度处理保持原协议。fold0 不使用。

固定读出使用 clean reference t9 FC2 的 folds1–3 训练 StandardScaler+LinearSVC(C=1)，不使用开发集拟合或适配。报告准确率、正确类 margin，以及相对同输入 clip 的预测一致率、FC2 余弦。响应报告均值、非零密度；完整图单位范数几何报告类内/类间散度和 Fisher。

priming 主对比为 Exact−Different，同时报告相对同版本 none 的差值之差，防止把一般抑制误判为重复特异抑制。预先固定 early t0–4、middle t5–9、late t10–14。平均响应下降不等于 sharpening；几何、稀疏与固定读出分别报告。按概念成块 bootstrap，仅作开发样本描述，不把时间步或噪声当独立样本，不做结果驱动参数搜索。
