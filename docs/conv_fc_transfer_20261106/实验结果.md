# FC 后期机制移植到卷积层：直接读取与轻量 SAE

完成 clean 小批量：ImageNet 16、THINGS 20 个目标；1260 条独立递归序列。原模型和 FC Hebbian 未改变。四种 branch/source × full、pool、shuffle、scale，以及 clip 的三种历史。非 clip 的无 preview 结果在严格恒等检查后共享同一基线。

直接读取使用512通道；SAE为逐空间柱512→固定32→64 latent，2112个学习参数。SAE只产生增益，不替换原512通道卷积表征及4096维FC。两种图来源共享同一数据集编码器；每trial两次preview写入，target冻结，保留柱内充分候选和柱间mutual top32。

ε=.03、λ=.03、侧向5步直接沿用FC后期设置，没有按开发结果搜索。SAE只用训练折24/30个目标及其preview拟合；各分支/来源的q RMS与κ₀也只用这些训练活动估计，开发提取前冻结。此采样是小规模训练侧定标，并非全量SAE训练或内层交叉验证。

## 主要结论

**三项机制已成功接入卷积临时记忆通路，但当前冻结点尚未通过“稳定重复抑制＋额外类别sharpening”的联合目标。** 实际接入的是独立匹配阈值、柱内零均值增益重分配、直接ReLU截零；没有复用旧训练集固定Hebbian图，也没有让SAE重建进入前馈。

早期 t0–4 的 full Conv4 suppression 如下；正数才表示 Exact 低于 Different，单位为百分比：

| 读取分支／来源 | ImageNet | THINGS |
| --- | ---: | ---: |
| 无Hebbian clip | −0.24275% | −0.07423% |
| 原512通道／rep4 | −0.13347% | +0.00509% |
| 原512通道／prd5 | −0.21673% | −0.06082% |
| 轻量SAE／rep4 | −0.22562% | −0.04850% |
| 轻量SAE／prd5 | −0.20127% | −0.07281% |

1. **匹配驱动抑制使部分重复差异向抑制方向移动，但尚不稳定。** 原通道rep4相对clip在两数据集均更接近所需方向，权重打乱后接近原基线。THINGS的+0.00509%非常小；八个 full 数据／来源组合的早期Conv4概念块95%区间全部跨零，不能把它认定为可靠suppression。仅抑制组的早期suppression均略强于对应full，局部增益没有再增强这个指标。
2. **局部减活动已经做到，下游没有等比例减少。** 相对各网络步实际进入算子的Conv4输入，Exact局部活动下降1.08%–1.97%；相对同历史clip，完整递归后的Conv4均值下降1.21%–2.22%。但部分SAE组合的FC2均值反而略升（约0.06%–0.11%）。这直接显示了局部活动下降不能替代全网络实际响应的检查。输入／输出分解见local_input_output.csv。
3. **完整增益尚未提供稳定的额外类别收益。** 早期Exact FC2相对同历史clip，ImageNet四组Fisher变化均为−0.042%至−0.145%；THINGS原通道两组为−0.062%／−0.237%，SAE两组为+0.215%／+0.074%。然而，8/8个full组合的FC2 Fisher都低于对应pool；7/8低于对应等均值缩放，例外是THINGS的SAE/rep4。故不能用THINGS两项微小正变化宣称增益方向已经普遍有效。
4. **固定FC2读出相对同历史clip基本保留，但不能称分数恒等。** ImageNet三组早期时间平均准确率不变、原通道prd5下降1.25个百分点；THINGS四组均增加1个百分点。原通道rep4在两数据集的FC2真实类别margin均略增（+0.0157／+0.0224），其他组合并非一致。FC1也已独立评价：ImageNet full四组早期准确率均下降1.25个百分点，THINGS不变。全部margin、AUC及两种时间汇总口径见fixed_svm.csv，不能用FC2的结果掩盖FC1变化。
5. **后期个别正suppression不等于联合成功。** SAE/prd5的晚期FC2 Exact−Different suppression为ImageNet约+0.0269%、THINGS约+0.0089%，但对应Fisher相对Different分别约−0.0573%和−0.0432%；没有同时获得重复抑制和类别几何改善。

本轮的积极结果是：活动量可以被温和、可控地降低，原通道rep4有部分固定读出margin收益，临时匹配机制对历史差异有可测的方向影响。未成立的结论是：SAE代理或完整局部增益普遍优于仅抑制／缩放，或当前参数已经解决卷积repetition sharpening。没有根据这些开发结果继续调参。

## 验收及实现边界

9项测试通过，包括激活门回投的能量梯度、无记忆恒等性、零支持、截零、累积、空间偏移和完整图Gram几何。两数据集各四个真实模型检查通过，重复Exact逐位一致；原网络PCoder5预测模块保持原实现。1260条序列的重置、写入、target冻结和协议内源代码哈希均验收通过；所有柱间最大度数≤32。截零前相对净增益误差最大约1.54×10⁻⁹，缩放对照19步均值匹配最大误差约2.98×10⁻⁸。详见final_audit.json。

开发提取前修正过一个缓存字段假设：旧参考文件没有完整FC1，因此重新从原训练输入采集同一clip基线下的无preview t9 FC1/FC2，再拟合固定头。该修正发生在任何开发结果之前，未改变SAE、定标或干预公式；原协议和修正记录保存在pre_development_fc1_cache_correction.json。原checkpoint未修改。

pool不是“逐时刻同权重同阈值”的严格因果消融：局部增益从第二段preview起即可影响后续源活动和写入，目标阶段的查询轨迹也会不同。这里比较的是两套完整闭环机制；不要把Fisher差异全部归于固定W下的一次局部乘法。图密度使用精确非零统计，update_traces中的活动阈值为归一化活动>10⁻⁷，两种诊断口径应分开阅读。

## 对照与解释边界

pool关闭局部重分配但保留同一匹配阈值规则，后续活动和阈值可分开；不是逐步固定阈值的因果干预。shuffle仅在两段preview完成后打乱通道/latent对应，Exact/Different共享同一排列，并已核对打乱前权重与full相同。scale是独立重跑整个递归网络，逐网络步匹配full的全局rep4均值；不强行匹配下游FC均值，也不把此后验均值对照当作独立产生的历史机制。

原通道和latent分支在不同维数上建图，因此同样top32不表示相同稀疏比例、有效边数或存储量。weight_statistics.csv报告实际图；update_traces.csv报告调制强度、阈值、κ和截零前平衡。

主要SVM为仅用folds1–3原FC clean t9训练的固定StandardScaler+LinearSVC(C=1)，分别读取FC1/FC2实际响应。fixed_svm.csv同时报告时间平均准确率、窗口平均决策分数的BA/宏AUC，以及margin。没有使用latent或SAE重建读出。

该批量沿用已经反复查看的开发概念，不能作为全新独立终测。所有时间窗口和对照在CSV中。paired_concept_bootstrap.csv是概念成块的描述性95%区间，未作多重比较校正；时间步不是独立样本。
