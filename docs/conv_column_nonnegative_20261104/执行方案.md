# 非负卷积柱内/柱间 Hebbian 小批量实验

2026-11-04 最终执行版。替代 signed 传播草案；此前 rep 分布审计保留作历史证据。

## 机制与控制
只干预 PCoder4。原 PCoder 更新完成后截断 rep>=0，侧向计算后作为同一个 rep 送入预测模块、保存状态及下游。预测误差梯度针对最终 rep 计算，不通过侧向迭代反传。没有正负双状态。FC 新旧 Hebbian、旧卷积短时 Hebbian 的计算和写入全部关闭；原网络参数不训练。
柱内全部通道对开放，保留全部正相关连接，无自身连接。柱间为3x3去中心、距离高斯权重、互为top32、反向配对。两部分分别用公共最大行和归一化。训练图像位置逐点中心化后汇总，方差正则为正通道方差中位数的0.1，最低1e-6。
图和RMS尺度从本数据训练折 clean、无preview、仅截断PCoder4的t9状态估计。每图等权，测试期间冻结。d=x+0.25E0r+0.125ELr；抑制池为本柱全通道均值与周围有效柱均值各半；r_next=0.5r+0.5d/(1+0.5I)，每网络步3次。不加硬门控。

## 执行矩阵
ImageNet训练256图，THINGS训练320图，均为原fold1-4。fold0每类确定性取2概念、每概念2图，测试16/20图。所有测试preview/背景概念和图像字节也排除于图训练。clean及seed2921 noisy；exact、same_concept、same_category、different_category；PCoder carry，2+2 preview和15 target步，无事件间灰屏。
9设置：original、clip、inhibition、excitation、intra、full、shuffle、matched、intra_budget，共2592序列（ImageNet1152、THINGS1440）。original不截断；其他均截断。intra_budget增益0.375与full总预算相同。shuffle用固定通道置换，保留度数/权重/空间距离。matched在该对照自身当前输入上计算full输出的均值，再整体缩放输入；这是局部算子幅度匹配，不保证整个递归轨迹与full均值一致。

## 实现和验收
柱内为1x1稠密计算；柱间先用掩码3x3卷积作为精确数值参考，尚未实现稀疏加速核。结构稀疏不等同GPU加速。输出保留float32完整CHW及FC特征，逐序列可续跑。实现测试包含Off恒等、截断精确、独立batch、邻域显式求和与卷积一致、最终rep梯度及1/3/5/20步有限值；实际运行校验每序列调用次数、旧Hebbian关闭及非有限值。
