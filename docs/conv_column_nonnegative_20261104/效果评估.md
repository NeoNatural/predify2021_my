# 卷积 Hebbian＋侧向抑制 pilot 评估

**结论：当前参数下，Hebbian＋抑制尚未表现出优于仅截断的整体优势。相对仅抑制有小幅下游几何改善，但分类和启动收益不一致。**

- 早期四内容平均ACC：ImageNet clean/noisy相对clip为−1.875/0个百分点，相对inhibition为−0.625/+0.3125；THINGS clean/noisy相对clip为−2/−3.25，相对inhibition为+1/+1.25。
- ImageNet noisy晚期full比clip高6.25个百分点，但比inhibition低6.25个百分点；不能把抗噪改善归功于Hebbian。
- 早期PCoder4归一化Fisher相对clip下降0.18%–0.51%；FC2相对clip提升0.09%–1.82%，相对inhibition提升0.27%–1.56%。这是很小的描述性收益。
- full相对clip的PCoder4类内与类间散度共同缩小约9%–11%；更高类内余弦不能直接当作类别分离改善。
- 早期PCoder4精确零值比例：clip约38.6%–38.9%，inhibition约39.7%–39.9%，full为0%。此处是精确零值统计，不等同所有新增正值都达到生理有效阈值；当前无硬门控，未获得响应稀疏化。
- 内容效应没有一致增强：ImageNet clean早期Exact−Different为clip 0、inhibition 2.5、full 3.75个百分点；THINGS noisy Same-category−Different为clip 7、inhibition 4、full 4个百分点。扩大启动差值不代表绝对准确率提高。

建议保留此版本为机制基线，暂不扩大到双层。下一轮先单独检验弱响应门控或侧向增益校准，并补适配读出，避免把固定参考头的分布迁移误判为类别信息丢失。不得把当前结果称作稳定获益或显著改善。

## 解释边界

每数据集仅一个留出折、每类2概念×2图，ImageNet16图/THINGS20图，noisy仅一种实现。时间、预览及噪声重复不是独立样本；不作显著性宣称。几何为测试小样本描述，没有置信区间。冻结参考读出的变化包含分布迁移；适配读出尚未拟合。PCoder4直接受干预，PCoder5/FC1/FC2为下游效应。

归一化类内散度和余弦改善不能单独证明类别分离，因为类间散度也可能收缩。无硬门控，柱间连接稀疏不代表响应必然更稀疏。
