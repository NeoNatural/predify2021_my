# 卷积柱内/柱间有符号 Hebbian pilot

状态：2026-11-04 开始实施；先完成实际 rep 分布审计，再进行连接拟合与机制测试。未完成阶段不得标为已有结果。

## 冻结机制
仅 PCoder4 首轮干预，PCoder5 后续单层验证。FC 新旧 Hebbian 均关闭，旧卷积短时 Hebbian 计算和写入关闭。原 VGG/预测模块权重冻结。原 PCoder 状态、反馈和误差更新保留。
训练连接用 clean 训练表征的正部 h=max(rep,0)，不写回状态。柱内所有不同通道均可连接，保留正则化正相关、零对角、对称，不做 top-k。柱间采用 3x3 去中心邻域、距离衰减及互为 top-32；反向边配对。空间共享权重，保留完整 CHW。两部分各用公共最大行和归一化。
应用使用原 signed rep：x=rep/s，r0=x，d=x+0.25 E0 r+0.125 EL r；I 为本柱平均绝对活动与邻柱平均绝对活动的等权和；r_next=0.5r+0.5d/(1+0.5I)。3 个侧向小步，无 ReLU，无硬门控。负值可保留、可通过侧向项改变。s 为训练折原 signed rep 的 RMS。最终表征一致用于状态、预测模块和下游；误差梯度针对最终表征求取。
连接学习按图等权，位置中心化后汇总；低方差项正则化。连接和尺度测试期间冻结，无跨 trial 状态残留。

## 数据与隔离
复用 native_categories_20261029 的类别与角色清单，不复用 FC 学习权重。ImageNet 四类，THINGS 五类。固定 fold0 留出，图和尺度仅用其余四折（256/320 张），训练所有视觉角色不得与测试概念/字节重叠。pilot 从留出折每类确定性抽 2 概念、每概念 2 图，共16/20图。当前为历史数据探索，不称独立确认。
实现验收用已有开发队列每类1概念2图，18图。植物开发仅1概念，不能检验其跨概念 same-category。

## 分阶段
1. 原 rep 分布：全五层，clean/noisy，exact/different，PCoder carry；记录 preview 与 target 全步。严格禁用全部旧 Hebbian 模块。统计 min/max/mean/meanabs/RMS、负数比例、低于 -1e-7 比例、负幅度占比和分位数；原 ReLU ff 与 PCoder rep 分开记录。实际观测后再判断负值是否重要。
2. 单元验收：Off 恒等、FC 关闭、预测/状态一致、每网络步恰好3个侧向步、无跨样本混合、边界与反向连接正确、非有限立即失败。比较1/3/5步，20步仅压力诊断。
3. 七组：Off、仅抑制、仅耦合、柱内+抑制、柱内柱间+抑制、打乱连接+抑制、幅度匹配。仅耦合使用与完整条件相同增益。补总兴奋预算匹配的柱内消融。匹配对照以绝对活动而非 signed mean 为尺度。
4. 主 pilot：PCoder carry-only；2+2 preview、target15步、四内容、clean及固定一个noise；36x2x4x7=2016序列，不含参考/训练。通过后追加噪声种子、PCoder5和双层。暂不恢复旧短时W，不叠加FC机制。

## 评价
PCoder4/5、FC1/2 全层记录 signed mean、meanabs、密度、负值、极值；完整CHW的 raw/normalized类内散度、类间散度、余弦及 Fisher；同概念与跨概念分开。noisy到clean参考的距离。固定原t9-B迁移头与训练折适配头分别报告。early t0-4主、late t10-14辅，保留全部时间点。内容效应为各内容减同设置different，再计算相对Off的差中差。小样本不据峰值宣称显著。
柱内用共享1x1稠密计算，柱间先实现数值可核对的固定稀疏模板。测建图、模块及端到端时间、batch1和批量吞吐、显存；不把置零直接称为GPU加速。图和模型每条件重新产生真实PCoder轨迹，禁止缓存输出重放替代递归计算。

## 推进条件
数值与状态检查通过，无活动塌缩；几何变化超出抑制/缩放/随机对照，读出没有明显受损。负值分布只决定解释，不按测试表现临时换机制。所有未执行项保持待执行标记。
