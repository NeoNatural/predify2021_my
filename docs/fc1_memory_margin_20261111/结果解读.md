# 冻结 FC1 记忆匹配与 margin 分析

2026-11-11。ImageNet 16 个 target、8 个概念；THINGS 18 个 target、9 个概念。采用已冻结 epsilon=.03、lambda=.03、5 步和 vanilla FC1 StandardScaler + LinearSVC。模型及分类器均从已有文件读取。仅进行推断和统计。

## 同总活动量的第一步

在同一 target 的初始状态查询两套 preview 记忆，S=.5 zᵀWz。四个输出（Exact/Different × full/pool）按单一比例缩放到该 target 四者中最小的整流后总活动量。pool 在第一步与 full 共用输入、记忆、阈值，关闭局部增益。缩放只用于读出诊断。

A 是 full 的 Exact−Different margin；G 是 A 减去 pool 的 Exact−Different margin。分类器及其标准化器保持冻结，输入为原 4096 维 FC1。

|指标，均值及95%区间|ImageNet|THINGS|
|---|---|---|
|Exact−Different 匹配 ΔS|0.65622 [0.34312, 0.96933]|0.16030 [0.12519, 0.19516]|
|A|−0.00299 [−0.01300, 0.00651]|−0.00061 [−0.00665, 0.00519]|
|G|0.00073 [−0.00408, 0.00580]|−0.00117 [−0.00629, 0.00335]|

Exact 匹配更强的 target 为13/16和15/18；A为正的为8/16和10/18。匹配增强并未伴随一致的分类 margin 收益。ΔS 与 A 的逐target Spearman相关分别为0.153、−0.119；与G分别为−0.150、−0.129。这些相关仅作探索性描述，尚未获得跨数据集一致的正关联。

## 自然的第0–5步轨迹

此分析保留真实活动幅度，直接读取生产更新函数各步输出。第0步三种历史逐target相同，无preview轨迹水平。

|配对margin差，均值及95%区间|ImageNet|THINGS|
|---|---|---|
|第1–2步平均 Exact−Different|−0.02445 [−0.04262, −0.00627]|−0.01140 [−0.01527, −0.00753]|
|第1–2步平均 Exact−无preview|−0.04381 [−0.06915, −0.01724]|−0.04630 [−0.06097, −0.03163]|
|第5步 Exact−Different|−0.02332 [−0.04102, −0.00562]|−0.01194 [−0.01744, −0.00645]|
|第5步 Exact−无preview|−0.04488 [−0.07096, −0.01777]|−0.05053 [−0.06729, −0.03377]|

Exact平均margin在第1–5步持续低于两种对照。当前冻结设置未表现出更早可读出的类别优势。第一步已出现主要下降，后续较快接近末步值。

自然轨迹的Exact劣势在同总量第一步比较中大幅缩小，提示总活动量变化对固定读出的影响值得重视。总量匹配是输出缩放后的条件比较，不能据此将所有损失归因于幅度，更不能证明具体受影响的是背景或实例细节。

## 统计与核对

- 所有均值按类别、概念等权。95%区间由类别内概念配对重采样5000次得到；保留每个概念内全部target、历史和步数。曲线为逐点区间。
- 每类概念很少，开发集已经反复分析，区间只反映这批概念的有限变异。结论限于当前34个开发target和固定分类读出。
- 两数据集第5步FC1与历史缓存最大绝对误差均为0；第0步一致、无preview恒定、target期间W固定、proxy前后哈希一致均通过。
- 四条件总活动量匹配误差为0，无零总量样本。输入、分类器、选择文件与定标文件的前后哈希核对通过。
- 本文第0–5步是FC1侧向更新步，不是整个Predify的外层时间步，也没有换算为行为反应时。
