# 幅度导致的准确率变化为什么需要单列，而不是删除

幅度收益本身可以有价值。研究目标包含平均激活下降，因此不能把所有幅度效应排除出功能评价。本轮保留原始幅度下的readout为主要功能检查，去幅度后的结果只用于解释来源，不是新的成功硬门槛。

把第i张图的向量写成 `r_i = a_i u_i`，其中 `a_i` 是范数，`u_i` 是单位方向。幅度 `a_i` 可能携带类别、刺激强度或可靠性信息；方向 `u_i` 表示神经元之间的相对响应结构。逐图L2归一化只保留后者，不代表前者一定是噪声。

需要区分：

1. 所有图统一乘同一正常数c。在训练集正确重新拟合StandardScaler时，均值和标准差也分别乘c，标准化后的输入不变。因此第一轮固定0.5缩放没有改变重拟合读出。
2. 每张图乘不同的c_i。样本之间的相对范数会改变，跨图拟合的StandardScaler不能把这种变化全部抵消；分类器的样本权重效果、边界和AUC可能改变。这可能是有用的增益调节，但不是方向结构已经改善的充分证据。
3. 冻结读出。`W r+b` 在输入幅度变化时会移动，而b没有同比例变化，准确率可能受影响。这是在检验与既有下游的兼容性。

所以两个问题分别回答：

- 原始幅度readout：整个处理是否帮助下游分类？
- 去幅度readout：移除每图范数之后，相对神经元响应是否仍更容易被读取？

只要在未见概念上可靠重现，幅度产生的分类收益仍是功能收益。它不能自动被解释为Hebbian语义关联变好；反过来，去幅度后收益消失也不能自动说明整个处理无用。第一轮匹配均值缩放的用途是归因，不能据此删除原始准确率变化。

几何指标同理：原始类内方差可以被统一缩放直接压低，所以并列报告原始与归一化W/B/Fisher，而不靠一个方差下降判定sharpening。最终仍围绕平均激活下降、表征区分度提高，并用大类readout验证功能意义。
