# 第二轮：稀疏 Hebbian 与自适应阈值

2026-10-28。目标继续是平均活动下降＋表征区分度提高；针对第一轮密集弱响应，额外约束活动支持不超过原图，不把活动稀疏本身当作成功。复用两数据集、两层、相同概念隔离五折。属于同一探索样本上的机制迭代，不是新增独立确认。

## 幅度不是需要排除的收益

原始幅度下的readout回答“下游分类是否改善”；逐图L2归一化的readout回答“去掉样本范数后方向结构是否更容易读取”。后者只是机制诊断，不是新的必要成功条件。幅度可以携带真实类别或可靠性信息，也可能通过冻结边界、正则化与有限样本训练改变预测。不能把幅度收益一律称作伪效果，也不能把它自动解释成方向几何改善。

全数据统一乘常数与每图不同缩放不同：前者在重新拟合、正确标准化的读出中应抵消；后者仍会改变样本相对范数。第一轮的固定0.5缩放验证了前者，而匹配输出均值的逐图缩放诊断了后者。第二轮主筛选继续保留原始幅度，只用原始readout作保护条件；angular readout完整报告但不否决原始幅度收益。

## 网格

继承训练集内中心化正协方差cov、带方差下限的正相关corr；与第一轮相同的输入尺度、统计、无自连接和非负兴奋性。每种比较dense、mutual top32、mutual top128。每对神经元只有互相进入各自top-k才连边，因此对称且每单元度数最多k。稀疏后统一重归一化最大行和至1，比较相同最大兴奋预算；这会增大保留连接的单边权重，不是“只删除边且其他权重不变”的消融，保留重归一化前的增益供解释。

三种活动机制：

1. 仅除法归一化，检验图稀疏是否足以防止响应变密。
2. 自适应soft阈值：在每张图、每步驱动上选择分位阈值，输出ReLU(drive−theta)，再除法归一化。
3. 自适应hard阈值：低于阈值静默，高于阈值保留驱动幅度，再除法归一化。

活动预算k=ceil(原图非零单元数×0.75或1.0)。非零判据为原始物理激活大于1e-7。阈值由当前驱动的第k和k+1大值中点给出，无标签。并列值可使活动数少于预算；无强制随机补齐。阈值否决单元立即清零，避免松弛更新留下弱正值尾巴。兴奋增益0.25或0.75；除法强度固定2，继承第一轮已探索结果；松弛率0.5、最多100步、相对更新残差1e-5。

共66配置，22基础家族；内层选出的主候选限制在稀疏＋adaptive家族。主三项评分同第一轮：三种log改善的最弱项、两内层折平均。优先共同改善、无零向量、收敛、逐图密度不增加和原始readout guard通过（BA不降超过2pp、AUC不降超过0.005）的候选；若无共同达标者，保留最接近目标及失败标志，不能强称成功。

## 对照与评价

保留baseline、固定0.5缩放、仅soft/hard自适应抑制、dense及sparse无自适应阈值、上轮固定最佳dense/corr/divide(.75,2)。再做选出稀疏连接重排、相同阈值预算而去掉Hebbian、逐图均值匹配缩放、尽可能支持匹配的阈值。记录实际支持数误差，不能将近似匹配称为完全匹配。

各家族在每个训练折重新估计统计及连接。原始ridge用于全部候选；外层对主候选、去Hebbian、均值匹配缩放和旧dense参考重新拟合固定C=1的SVM。原始冻结SVM也报告。baseline/主候选另做逐图L2归一化的ridge和SVM，属于机制诊断。AUC折内计算后平均。

保留均值、归一化W/B/Fisher、原始readout、非零比例、逐图支持比、激活数量增加的图片数、原先静默单元被招募的比例及活动量、低于每图最大值1%的弱响应活动量、收敛与零向量、分大类指标。几何在各外层测试折内计算，不拼接不同拟合模型的特征。报告五折描述性结果，不将其当独立受试者或宣称显著。

代码及协议在运行前保存哈希和快照。验证稀疏度数、阈值预算、不留泄漏尾巴、无Hebbian方向负对照、旧dense结果回放。原模型、第一轮结果和vanilla缓存保持原样。
