# SAE只计算Hebbian增益：通路与参数预算修订

本文件按最新要求修订后续方向。这里只制定可审查的候选结构，没有训练新SAE、接入Hebbian、搜索参数或修改原模型。以前的验收模型和报告保留为历史结果，不覆盖。

## 1. 当前通路约束

- 原始4096维FC响应始终是被增强/抑制和继续前馈的主体。SAE重建、latent及重建残差不进入主前馈通路，也不直接作为SVM输入。
- SAE仅为临时Hebbian关联和增益估计提供辅助坐标。投回原空间的是无量纲增益控制信号，不是替代原响应的重建。
- SVM只检查vanilla原FC及施加Hebbian增益/抑制后的原4096维FC表示。原固定头及必要的适配头均遵守这一输入口径。
- 此前关于修补“重建输出＋SVM”的建议不再作为下一步任务；相关读出诊断只解释旧验收结果。后续不继续拟合latent或残差SVM。
- 编码器/解码器离线训练后冻结；每trial只有临时Hebbian记忆清零、由本trial两帧preview写入，target只读。辅助SAE不能在target阶段学习。

## 2. 参数与存储两种口径都列明

FC1、FC2均为4096维。每层原完整Hebbian矩阵有4096²=16,777,216项；去掉对角后有16,773,120项。它们是矩阵条目数，不是当前实现实际独立存储的数量。

当前PreviewMemory只存两帧4096维外积因子及两个系数：8194个浮点数值。对角修正按需计算，不另存完整矩阵。这是临时状态数量，与SAE离线可训练参数不同，不能混称为同一种学习容量。

旧512-latent SAE每层有4,194,816个可训练参数。后续候选同时满足更严格的实际状态预算，而不只满足1678万矩阵项这一上限。

## 3. 一组预算内候选：固定32维变换＋64-latent共享权重SAE

设固定变换P：R4096→R32，再使用

\[
v=(Px-\mu)/s,\qquad z=\operatorname{ReLU}(Av+b),
\quad A\in\mathbb R^{64\times32}.
\]

辅助解码器与编码器共享同一矩阵：\(\hat v=A^\top z\)。SAE训练重建的是固定32维坐标，不要求用它重建或替代完整4096维FC。\(\mu\)为训练折估计的32维固定中心，\(s\)为一个固定尺度。活动latent数量自由变化，不使用top-k配额。

P采用固定种子定义的符号变换、归一化快速Hadamard变换及32行选择：\(P=RHS\)。计算P及其转置时使用同一确定性算子，**不学习或保存一个4096×32稠密投影矩阵**。所需种子、行索引及可选缓存的符号位也要记入实现的存储清单，不能藏入“无参数”名义下。

每层预算：

|组件|浮点参数或状态数|
|---|---:|
|共享编码/解码矩阵A|2048|
|编码bias b|64|
|可训练参数合计|**2112**|
|训练折固定中心和尺度|33|
|显式64×64临时Hebbian矩阵|4096|
|上述浮点总量|**6241**|

两层分别训练，合计4224个可训练参数；上述浮点总量为12482。即使潜变量Hebbian矩阵完整存储，每层仍低于当前8194因子数值的基线。若继续使用两帧因子表示潜变量记忆，每层浮点总量为2275。

固定种子、32个行索引、可选4096个符号位只需额外少量元数据；不需要额外的大型常量矩阵。实际实现时仍应分别报告可训练参数、固定统计、临时状态、元数据、峰值工作空间和运行开销。训练优化器状态及瞬时激活不属于上述推理期参数清单。参数减少不等于运行时间必然减少。

这是单组候选，并非已验证的最佳结构。固定32维变换可能限制内容选择性；小参数量能避免重用过大的代理，但不能自动保证sharpening收益。若预算按原完整稠密矩阵理解，本候选仍满足；不需要据此放宽结构规模。

## 4. SAE输出只生成控制增益

preview由原vanilla网络获得两层响应，各自经过固定P和冻结SAE形成z。沿用目前归一化、去对角外积和ρ=.5的临时写入规则，只将记忆坐标从4096维换成64维。两个preview写入后冻结Wz。

target读取可表示为

\[
z=E(Px),\quad h_z=W_z z,\quad q=P^\top A^\top h_z,
\]

\[
g=1+\eta\tanh(q),\quad 0\le\eta<1,\qquad
x'=\mathcal I(x\odot g).
\]

这组公式用于明确通路：\(q\)是增益控制信号，\(\mathcal I\)是另行固定的抑制处理，不额外学习一个4096维增益投射矩阵。具体增益尺度及抑制规则应在下一次独立实验前冻结，不依据测试结果搜索。

没有临时记忆时\(W_z=0\)，则g=1；关闭普通抑制的零编辑条件严格回到原FC。若保留普通抑制，则回到对应仅抑制基线。乘性增益不会把原本严格为0的FC单元点亮；这不保证微弱非零响应不会被放大，也不保证平均活动一定下降，仍需实际统计。

这里从来不使用\(x'=\operatorname{Dec}(E(x))\)，也不使用“原响应＋SAE重建差值”作为响应更新。SAE的有符号解码只服务于Hebbian控制量的生成，原FC值由原输入及其增益/抑制决定。

## 5. 原前馈及SVM位置

\[
x_1\xrightarrow{\text{原FC1值×辅助增益/抑制}}x'_1
\xrightarrow{\operatorname{ReLU}(B_2x'_1+c_2)}x_{2,\mathrm{in}}
\xrightarrow{\text{原FC2值×辅助增益/抑制}}x'_2.
\]

FC2辅助通路读取实际到达的4096维输入，不能用旧缓存FC2冒充串联结果。SVM检查x1、x1'、实际FC2输入及x2'等原FC空间表示。增益调制导致的SVM变化属于功能检查；SAE重建、z、q及重建残差均不直接送入SVM。

## 6. 后续验收目标相应修订

先检查参数预算、目标阶段辅助参数冻结、无记忆时增益为1、零编辑恒等和真实桥接。随后才在独立实验中比较Exact、Different、无preview及仅抑制、同均值缩放、临时权重打乱。

主要结果仍是原FC1和FC2的平均活动、非零/微弱响应、类别偏好、类内W与类间B、Fisher，以及原FC上的SVM保真。辅助32维重建和稀疏性只用于训练监控；不再以“重建响应能否替换FC并被SVM读取”作为代理的主要验收目标。

当前尚未实现或训练这个候选，也未执行新的Hebbian实验。原模型、旧SAE及所有旧结果均保留。
