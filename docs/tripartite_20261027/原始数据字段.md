# 2026-10-27 原始记录

各数据集 manifest 固定train/dev/test的目标和概念、preview配对、主/弱条件与噪声基种子。每张图×噪声对应一个 `image_*_seed_*.pckl`，记录28条件的15步FC2、原1000类logits、绝对激活、内部预测误差、目标像素摘要、W范数和真实提交事件。

- `fc2` 为float16保存的4096维读出特征；分类前转float32。
- `activation` 的四列按 FC2、FC1、PCoder5注入层、PCoder4注入层排列。
- `weight_norms` 按两段preview边界排列，每项的两层顺序为PCoder5、PCoder4。
- `commit_events` 记录实际调用，PCoder5/4各在preview0/1末尾一次，共4事件；无记忆和PCoder-only为0事件。
- `target_W_frozen` 在15步后逐元素比对W确认。
- `preview_indices` 是基准呈现计划。随机/前馈初始化参照为target-only，不处理该preview计划，故其 `weight_norms` 与 `commit_events` 都为空；gray初始化的四载体实际处理两段preview，再按载体定义恢复或保留状态。
- `target_seconds` 含目标特征提取/同步开销，不是部署时延。本轮不以计算效率判断价值。
- `noise_stats` 用标准化输入单位，包含完整画布std、实际物体区域std/RMSE，不能当成RGB噪声σ或声称新旧尺寸有效噪声相同。

`stimulus_*_seed_*.npz` 保存实际标准化target与对应clean画布。`previews_*.npz` 保存五内容各两段实际preview画布。PNG仅供显示，逆标准化后裁剪RGB；模型和分析使用原始张量。

grey.json保存22步的稳定性选择轨迹。每个提取目录的grey_state_hash记录相同共同状态；缓存并恢复rep/prd/grd/prediction_error，避免重复计算不影响任何目标轨迹。

模型/依赖/权重/版本见implementation.json及source_snapshot。每目录provenance和source.py固定实际runner版本；head.pckl与head_source_*记录新读出及拟合源码，freeze.json固定确认前的方案摘要，analysis_snapshot.py为当时分析程序。
