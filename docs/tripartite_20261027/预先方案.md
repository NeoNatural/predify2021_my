# 横向三区布局下的 Hebbian × PCoder 实验

2026-10-27。根据引用对话最后一轮方案执行，并纳入用户本轮明确要求：联合、PCoder-only、Hebbian-only 必须全部两两比较。主分析按 target t0–t14 对齐，计算效率不作为继续门槛。

## 数据与划分（提取前冻结）

ImageNet 和 THINGS 统一为动物、服饰、食物、车辆，使用相同的精确映射概念及每概念图片配额。每数据集训练 80 张（每类 10 概念×2 图）、开发 32 张（每类4概念×2图）、确认64张（每类8概念×2图）。目标概念在三个集合间互斥；preview 仅来自相应集合的概念池，其他 trial 的全部 target 禁止进入 preview。读出层面的概念隔离不代表 VGG 预训练从未见过这些语义类别。

THINGS 沿用严格 WordNet 对应及已知 ImageNet 图片来源排除、文件字节重复过滤。确认图排除历史 1000 张 cohort、之前所有读出实验目标和已知 preview；训练/开发允许使用已查看数据，不将它们重新称为确认。库存限制：衣物仅42张从未查看图，食物46张、车辆52张；按每类16张确认图而非任意扩样。ImageNet 确认同样排除全部已知历史 target/preview，保留相同概念与图片配额。划分和库存见 inventory.json / 各数据集 manifest.json。

四类不能各提供四个互异的异类大类，因此基础 preview 从另三类各取一个物体，再平衡地重复其中一类（使用不同概念/图片），两边相同规则，不把植物偷偷重新引入。prime slot 在第二段 preview，左右在每个 split 的每个类别内各半。

## 输入和状态

224×224 完整画布送入一个网络，沿宽度分左、中、右区域，中心约37、112、187；物体64×64。两段清晰双图 preview，各2步；target 中央、noise .5，噪声先加在标准化224物体后缩放。保存实际 target/clean 和所有 preview 画布及缩放后噪声统计。旧34像素布局仅做开发数据的小型描述性敏感性参照。

每个新 trial 清零 W。共同灰屏状态从前馈初始化开始，关闭所有 Hebbian 更新；仅根据灰屏 PCoder 表征稳定性选择时长（全部5层相对变化<1e-4，连续3步，最多128步）。选得 **22 步**，不使用目标准确率选择。保存并恢复 rep、prd、grd 和 prediction_error；状态摘要应在所有数据集/阶段完全一致。

无 carry 时，每段 preview 及 target 均从共同灰屏状态开始，Hebbian-only 保留已提交 W；PCoder-only / 联合从上段状态延续。无记忆 W=0；target W 冻结。随机初始化和前馈初始化的 target-only 为次级参照。

## 条件和模型

主强度：无记忆1条件 + Hebbian-only/PCoder-only/联合各5内容（exact、同概念不同图、同大类不同概念、异大类、中性slot），共16条件。额外两个初始化参照。弱强度为 Hebbian-only/联合各5内容，共10条件。合计28条件，每图3噪声实现。

PCoder4/5 注入，coeff=.05（主）或 .0125（预设次级），decay=.5，inh=4，稀疏阈值=.9。FC 动态更新关闭；FC Hebb 在已有 ReLU 后且零W/cut=0时为恒等运算，直接旁路其计算。主干及PCoder增益、权重不变。每段 preview 结束提交一次 W，监测真实 commit 调用，不允许 target 更新。

每数据集正式 train6720、dev2688、test5376序列，共14784；两个数据集合计29568。旧布局另各8张开发图×1噪声×7条件，共112序列，四种载体 exact/neutral（无记忆只需一个条件）。验收另计。

## 读出与主要对比

主要：逐时间点、条件内、概念分组5折CV的 StandardScaler+LinearSVC(C=1)，所有条件/时刻共用折划分，噪声随概念分组，标准化只在训练折拟合。主层FC2，完整报告15时间点，不挑层/挑时刻。

关键对照：训练集拟合一个跨时间/载体/内容的共同冻结读出。为避免重复状态过多，按事先确定的轮转规则，每图×噪声×时间点选择一个内容身份：identity=(类内图片序号+噪声序号+t) mod 5。取无记忆、该身份PCoder、该身份Hebbian的两种强度、该身份联合的两种强度；后两种载体的每条记录权重为0.5，其余为1。每图行数为3噪声×15时刻×6状态=270行，权重合计180；全80图21600行、有效权重14400。每图总贡献和四载体权重完全一致，每图的每个内容/强度配额一致；内容及时间配额在类别内平衡。StandardScaler与SVM同时使用这些预设样本权重，C=1；不依据开发/确认成绩挑模型。模型最多50000迭代，未收敛仅升到200000，不换C。测试提取前冻结读出、数据、方案和实现摘要。旧读出仅历史诊断，不作新布局主要判决。

明确报告全部三种记忆两两差值：联合−PCoder、联合−Hebbian、PCoder−Hebbian；另报告Hebbian−无记忆、PCoder−无记忆、联合−无记忆。对每种内容、每种强度完整给出。交互单独计算为联合−PCoder−Hebbian+无记忆，不凭联合最高声称协同。exact另对全部内容控制比较。

## 统计边界与峰值

预设窗口：早期t0–t4、中期t5–t9、晚期t10–t14、全程t0–t14。描述性报告峰高、首次峰时、各条件各自峰差、同一时刻条件差、窗口平均准确率；不将测试曲线用于改窗口。峰值不标推断显著性，因为本轮不运行包含重新拟合+重新选峰的完整嵌套重采样。

CV折和三噪声均非独立样本。共同冻结读出：以概念为簇、保留其全部图片/噪声，报告bootstrap区间、概念簇符号置换、每噪声差值。预定主检验为三个记忆两两对比及Hebbian−无记忆（主强度exact），使用全15时刻的平均正确率差；两数据集、四对比共8检验Holm控制。完整时间线区间为探索性描述，不以逐时刻未校正p宣布显著。

交互的预定次级检验为共同读出、exact、全时间窗：两数据集×两强度共4检验单独Holm控制。即使交互为正，也需要结合联合对两个单独载体的实际优势解释，不把非线性准确率上的交互直接当作普遍的生物机制协同。

条件内MVPA：准确率、margin、混淆、错误转移、各噪声方向只作描述；未覆盖分类器重拟合的不确定性。CV按目标概念分组；同一确认池中的背景preview概念可跨CV折出现，因此这不是所有背景输入也完全未见的CV。独立共同读出的训练/开发/确认包含preview概念池的隔离更严格。若要正式宣称某峰/某时间点的信息优势，需要另加完整重新拟合的概念标签置换及时间/对比校正，本轮不伪造此类显著性。

弱强度为预定敏感性检查，不挑胜者取代主强度。独立确认只在布局、灰屏、参数、读出、主要对比和峰值定义冻结后提取。无严重地板/数值异常/极端抑制则继续；灰屏时长、模型参数不按开发分类最优选择。
