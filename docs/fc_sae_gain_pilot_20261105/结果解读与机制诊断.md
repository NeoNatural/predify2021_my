# 轻量SAE增益：状态通过，干预保真但sharpening收益尚未显示

本轮只使用一组预先冻结设置，测试仍为ImageNet16个、THINGS18个clean target。SAE只生成Hebbian乘性增益；主前馈和所有SVM均使用原4096维FC表示。不把辅助重建、latent或残差送入SVM，也不把它们替代原响应。

## 1. 结构与状态验收

固定32维快速投影＋64-latent共享编码/解码矩阵，每层2112个可训练参数。加上33个固定浮点统计和4096个临时Hebbian矩阵数值，共6241个浮点数。投影还保存4096字节符号和256字节行索引，单层主要张量负载29316字节；固定种子等少量元数据、控制/审计副本及临时工作空间另计。

仅训练fold1–4的vanilla target与preview用于辅助拟合，两个角色的总损失各占一半。没有分类监督、验证集挑选或超参数搜索。每trial清空64维临时W，preview写两次；target写入被拒绝，逐更新W哈希固定，SAE参数及统计也不变。倒序重放一致、无preview严格等于vanilla、原零单元局部不被点亮、真实原始桥接及缩放均值匹配均通过。

本轮更换了记忆坐标，因此不要求64维W和旧4096维W数值相同；保持的是同一批vanilla preview输入、归一化去对角外积的写入形式和trial生命周期。

## 2. 主方案的效应很小

suppression按同target比例计算后按类别/概念等权；正数表示活动更低。

|数据/层|Exact−Different suppression%|Exact−无preview suppression%|Exact相对无preview ΔFisher%|Δ最高偏好组份额pp|
|---|---:|---:|---:|---:|
|ImageNet FC1|+0.225|+0.545|−0.080|+0.049|
|THINGS FC1|+0.114|+0.464|−0.114|+0.030|
|ImageNet FC2|+0.286|+0.659|−0.092|+0.041|
|THINGS FC2|+0.153|+0.526|−0.124|+0.028|

主方案相对Different在FC1分别13/16、14/18个target更低，FC2为15/16、14/18；相对无preview，全部34个target两层活动均更低。但幅度都小于1%。Fisher相对无preview略降，偏好集中略升，不能把这组微小变化称为已经提高了整体表征区分度。类内W相对无preview增加约0.14–0.26%，也不是稳定的类内收紧。

## 3. 临时记忆有内容对应性，读取作用偏弱

第一步latent匹配κ=zᵀWz/‖z‖²的均值：

|数据/层|Exact|Different|
|---|---:|---:|
|ImageNet FC1|0.0794|0.0261|
|ImageNet FC2|0.1060|0.0326|
|THINGS FC1|0.0653|0.0375|
|THINGS FC2|0.0939|0.0376|

FC1两个历史读取相同原输入；FC2这里的数值使用各自实际桥接输入，因此同时含上游影响，不是完全相同FC2查询下的纯记忆比较。打乱64维latent单元对应后，历史相关活动差大幅减弱，支持内容对应参与了效应。它不是多次置换显著性检验。

η=.75是tanh增益的最大幅度系数，不表示实际单元改变75%。当前PᵀAᵀh形成的控制信号较小，第一步Exact的逐图最小/最大增益均值约0.96–1.04，群体平均增益接近1。正负调制及由正向增加量驱动的抑制池共同产生小幅净下降。本轮没有观察结果后额外放大q、归一化q或提高η来制造更大效应。

## 4. 对照没有支持明确的额外sharpening收益

记忆驱动仅抑制保留同一临时W和假想正向增加量生成的池，只把局部增益设为1。

|数据/层|完整方案Exact−Different suppression%|记忆驱动仅抑制|
|---|---:|---:|
|ImageNet FC1|0.225|0.243|
|THINGS FC1|0.114|0.118|
|ImageNet FC2|0.286|0.336|
|THINGS FC2|0.153|0.229|

仅抑制已能复制相近、部分更强的suppression。完整方案相对Different的Fisher比值略好于仅抑制，但相对无preview仍未提高；不能据此认定局部增强提供了净sharpening收益。

双层缩放按定义复制均值差，却保持FC1方向几何，FC2几何也仅有很小桥接变化。完整方案相对无preview的Fisher略降，而同均值缩放约保持。这说明目前没有显示出值得用几何变形换取的优势。权重打乱是内容对应对照，不是功能正确性的充分条件。

## 5. 原FC通路与读出

原固定SVM在主方案的Exact、Different、无preview下，ImageNet两层BA均81.25%，THINGS两层均80%；对应AUC也与vanilla相同。分数可能轻微改变，不能把BA/AUC不变等同于所有决策分数严格相同。共享适配头和分条件辅助头均只在相应原FC训练表示上拟合，完整结果见《轻量SAE增益小批量结果.md》。

原严格零单元不会被局部点亮。FC1的活动比例与vanilla相同；FC2最终活动比例只略高于vanilla，来自桥接后输入活动集变化，而不是SAE重建引入新响应。有限步混合仍保留弱响应尾部，不是硬稀疏化机制。

FC2局部Exact平均活动相对实际输入降低约0.55%/0.48%，局部Fisher约下降0.09%/0.12%。最终串联没有重现旧加性减法实验中明显的FC2输入抬高，但也没有获得更好的类间/类内分离。完整原空间低活动与sharpening指标仍需分开判断。

## 6. 本轮判断

状态、参数预算、增益旁路和原FC读出路径均按要求完成验收。这组参数表现为内容相关但较弱的抑制，并保持原固定读出；没有显示相对无preview及同均值缩放的稳定sharpening提升。

这只是一个小批量默认点，不是轻量代理不可行的证明，也不是最优增益或抑制参数。后续是否对训练侧控制量定标或调整兴奋/抑制关系，应另行预先定义；本轮没有接着搜索或改动。
