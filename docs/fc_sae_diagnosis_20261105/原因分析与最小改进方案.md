# SAE泛化与重拟合SVM下降：原因分解与最小方案

本轮只核对数据和已保存模型，并作解析投影、固定分类头的诊断消融；没有重新训练SAE或SVM、没有接入Hebbian、没有参数搜索，也没有修改原模型或旧验收结果。

## 1. 训练究竟覆盖了什么

**训练覆盖测试中的大类，但没有覆盖测试中的具体概念。** SAE沿用了原SVM的概念隔离划分，而不是同概念下随机拆分图片。

|数据|大类|SAE拟合概念|正式fold0概念|开发复核概念|训练与两类测试的概念重叠|
|---|---|---:|---:|---:|---:|
|ImageNet|animals/clothing/food/vehicles|64|16|8|0|
|THINGS|animals/clothing/food/plants/vehicles|80|20|9|0|

计入所有训练preview视觉角色后，训练概念仍只有64/80个，测试概念没有通过preview进入拟合。例如THINGS中的bamboo属于训练概念，fern属于正式测试概念；两者的大类plants已经覆盖，具体对象概念则隔离。

因此上一轮测的是“未见概念的重建泛化”，比“已经知道的概念、换一张新图片”更严格。后者目前没有独立结果，不能根据现有误差直接说SAE连同概念新图也无法处理。即使原始VGG预训练见过某些概念，也不等于后来单独训练的SAE获得了这些概念的FC响应样本。

如果最终研究目标允许SAE预训练覆盖测试概念、但测试图像完全隔离，这可作为另一个明确的“概念已见、新图像未见”设置；不能把它和当前端到端未见概念泛化混称，也不应把现有测试图片补回当前训练来降低误差。

## 2. 样本不足很可能重要，但不能只用一个样本数解释

每层辅助模型有4,194,816个可训练参数。ImageNet只有256个单物体训练target及648个去重preview，THINGS为320及828。独立画面合计904/1148，但preview组合重复使用训练概念、物体和背景，不能等同于904/1148个独立新对象。训练损失按角色各占一半，因此每个target的损失权重大约是每个preview的2.5倍。

512个latent也大于256/320个独立训练target；训练target可以被高度精确地表示，并不意味着学到了跨概念稳定字典。实际表现是：训练target的整流后FVU只有0.04–0.14%，隔离概念为31–42%，平均活动latent由约78–104增至221–230。这是明显的训练/测试失配与过拟合表现，不是训练目标还没有拟合好。

目前没有在同一评估集上做样本规模学习曲线，也没有同概念新图验证，因此不能把误差占比归因成“样本数导致多少、概念变化导致多少”。更准确的描述是：**有效图像及概念覆盖相对模型容量不足，叠加了严格的概念分布变化；单纯重复现有训练画面或继续压低训练误差，没有证据能解决它。**

## 3. 现有字典的覆盖确实是主要瓶颈之一

本轮没有另训字典。只对冻结decoder做QR分解，考察其现有仿射子空间能表示多少测试响应。设物理空间decoder为\(s(b+Dz)\)，\(P\)为D列空间的正交投影，\(v=x/s-b\)，则未整流重建误差可分解为

\[
\|x-\hat x\|^2=s^2\|(I-P)v\|^2+s^2\|Pv-Dz\|^2.
\]

第一项是当前decoder子空间外的误差；第二项包括编码器推断、非负与稀疏约束等带来的额外误差。使用任意有符号系数进行投影只提供乐观下界，不是新的可运行SAE，也不保证非负稀疏编码能达到它。该分解针对**未整流重建**，故下表总FVU略高于此前整流后数值。

|正式fold0|原始重建FVU%|decoder子空间外FVU%|编码/约束额外FVU%|子空间外误差占总误差|
|---|---:|---:|---:|---:|
|ImageNet FC1|43.63|29.66|13.97|68.0%|
|ImageNet FC2|35.26|22.37|12.89|63.5%|
|THINGS FC1|43.02|28.49|14.53|66.2%|
|THINGS FC2|33.34|21.20|12.14|63.6%|

这说明即使在冻结字典中给每张测试图求最优、可带符号的系数，仍有较大误差。只修编码器或减轻L1，不能消除当前字典子空间外的这部分误差。它支持优先处理学习到的覆盖与泛化，但不证明512维的任何字典都存在同样的误差下界，更不证明扩大宽度是唯一办法。

## 4. 重拟合SVM下降已有较直接的原因证据

此前只提出“标准化可能放大重建误差”；这次对现有分类头作了只读消融，证据更明确。

原始训练FC中有34/52/45/46个维度完全恒定，原固定SVM在这些维度的系数为0。SAE重建后它们出现了很小的训练方差；重新拟合StandardScaler把这些小变化转换成单位方差特征，新SVM于是可以使用它们。在fold0上，这些维度的标准化RMS却达到约6–17，属于很大的训练/测试变化。

[StandardScaler的定义](https://scikit-learn.org/1.5/modules/generated/sklearn.preprocessing.StandardScaler.html)是\((x_j-\mu_j)/\sigma_j\)。若\(\sigma_j\)很小，物理幅度很小的变化也会被放大。固定C=1并不让物理空间正则保持相同：若物理系数\(B_j=w_j/\sigma_j\)，则\(\|w\|^2=\sum_j B_j^2\sigma_j^2\)，小\(\sigma_j\)使很大的物理敏感度也可能只有较小的正则代价。

诊断只使用“原训练响应方差严格为0”这一规则，没有试多个阈值。对现有重拟合头，去掉这些标准化维度的分数贡献，其他权重及截距完全不变：

|正式fold0，BA%|原重拟合头|去掉这些贡献后|原固定头读取同一重建|
|---|---:|---:|---:|
|ImageNet FC1|59.38|79.69|79.69|
|ImageNet FC2|67.19|81.25|82.81|
|THINGS FC1|62.50|77.50|76.25|
|THINGS FC2|71.25|81.25|78.75|

开发小批量也一致：去掉这些贡献后四组BA为75/68.75/85/80%，与相应固定头读取重建的BA相同。训练BA仍约99.7–100%。因此这种读出对微小重建特征的过拟合解释了本轮相当一部分重拟合退化，不是所有下降都代表SAE删掉了类别信息。

这个消融不是重新拟合后的新分类器，不能把这些恢复值冒充某个新训练方案的成绩；它也没有降低SAE重建误差。修复SVM读出这一项，不能替代字典保真验收。

## 5. 最小改进方案：先固定两项，不开展网格搜索

### 第一步：仅修读出中已定位的问题

从原始训练target计算一次可变维度掩码：\(M_j=\mathbf1[\operatorname{Var}_{\rm train}(x_j)>0]\)。在重建响应进入StandardScaler之前应用该固定掩码，再按原设置拟合C=1 SVM。原固定头保留。掩码不看测试响应，不做小方差阈值搜索，也不使用测试标签。

这一步不需要重训SAE。首先只改这一项，避免同时筛选其他弱特征、改变C或更换分类器。若之后仍需研究标准化本身，再把“冻结原vanilla训练均值/方差”作为单独对照，不与本次最小修正混合。

### 第二步：同配置SAE增加训练内验证与检查点选择

保留512宽度、L1=0.1和原优化器，只在原训练fold1–4内按每概念预先固定一张图片作内部验证，其他图片拟合。必须同时移除所有含这些验证原图或视觉副本的训练preview画面，避免图片通过另一角色进入训练。具体概念仍有其他训练图片，因此该验证才是在测“同概念新图”。

内部验证只看重建及稀疏统计，使用预先指定的重建指标选择≤1000步中的检查点，不依据SVM或外部测试分数选模型。当前fold0/开发队列保持隔离，仅用于固定方案的一次回归验收。它们已经被查看过，后续多轮设计比较不应再把它们当作全新的盲测证据。

这提供一个最小区分：若内部同概念验证好、未见概念仍差，概念覆盖是主要差距之一；若两者都差，则图像覆盖、容量/正则和编码泛化都需要处理。早停可能改善泛化，但本轮没有验证，不能承诺恢复。

### 如果该次验收仍不够：优先增加独立训练覆盖

下一项优先增加训练概念的独立单物体图像，并视研究目标拓展与外部测试隔离的训练概念。不要把更多同图增强/重复preview计作等量独立样本；也不应先扩大字典去进一步压低训练误差。若要改成SAE已见测试概念、仅图像隔离的设置，另列实验口径，保留当前跨概念基线。

最小首轮就是“训练定义的读出掩码＋一个同配置、训练内验证的SAE”，没有宽度、L1、学习率或C的网格，也不新增分类监督、Hebbian或原模型变更。本轮仅提出上述方案，尚未执行新的拟合。
