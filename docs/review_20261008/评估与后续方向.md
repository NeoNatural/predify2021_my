**Predify–Hebbian 项目结果复评与后续方向（2026-10-08）**

我的总体判断是：项目已经建立了可靠的实验框架，并获得了值得继续研究的现象，但目前最有支撑的成果是“递归系统的中等噪声鲁棒性”和“记忆改变隐藏表征及其时间过程”，还不是“Hebbian priming 提升识别”。下一步应优先查清记忆带来的收益与代价，而不是继续寻找某个显著的层或时间点。

本次评估限定于当前 `predify2021_my` 的 dense 模型。没有把相邻 THINGS 或稀疏项目当成已经验证的证据。阅读了已有综述、实验配置与执行/分析代码；重新加载 11 组 vanilla 对比的原始结果、14 个正式 carrier 文件、3 个 clean no-Hebb 文件，以及固定读出的逐样本预测；补算无记忆基线、精确配对检验、交互效应和多重比较敏感性。没有重训模型或重跑 GPU 实验。

新增统计由 [审计脚本](../../analysis/review_20261008.py) 生成，使用 20,000 次逐图片配对 bootstrap、seed=20261008。置信区间均为探索性点估计区间，条件于现有模型、噪声 realization、样本及已拟合读出器。未覆盖模型训练、类别抽样、噪声种子或读出器训练的不确定性。与旧报告的小幅 CI 边界差异来自 bootstrap 种子和次数不同。

**1. 证据支持到哪一步。**

| 命题 | 当前判断 | 主要依据及边界 |
|---|---|---|
| Predify 系统改善中等高斯噪声分类 | 当前最稳的正向结果 | 1000 个配对 target；noise 0.5/0.75 的 Top-1 分别增加 3.4/3.3 个百分点 |
| 对遮挡、clean、极强噪声都有鲁棒性收益 | 不支持这种泛化 | t9 遮挡差值约 −0.1～+0.6 pp；clean −0.1 pp；noise 2.0 为 0 pp |
| Hebbian prime 会改变表征 | 支持，在当前模型和样本内成立 | no-Hebb 下无相应分类效应；one-back 与 no-prime 数组完全相同，two-back 有小幅数值差异；开启记忆后出现表征变化 |
| 局部 sharpening 等于分类改善 | 已有明确反例 | foveated noise 0.5 的 Conv4/5 几何符号满足 sharpening，但 t9 分类下降 1.6 pp |
| 模型完整复现了论文的 sharpening | 仍是部分、探索性对应 | clean 阶段没有同点 suppression+decoding 的严格联合通过；degraded carrier 阶段存在未校正点 |
| Same prime 已带来最终决策净收益 | 尚未证明 | 最佳 t9 固定读出候选只优于 Different，未优于无记忆 |
| Hebbian 与 PCoder carry 有协同增益 | 尚未证明 | 新算的 t9 超加性交互 CI 跨 0 |
| 同图 prime 的效应就是对象特异记忆 | 现有设计不能单独识别 | Same 是同图；Different 来自另一大类，混合了实例重复、类别一致性与异类干扰 |

“未证明”并不等于效应为零。尤其 N=200 的分类差异往往由很少几个样本决定，区间仍较宽。

**2. 最可信的成果：中等噪声下的递归系统收益。**

从原始 logits 重新计算，与既有均值一致：

| 输入 | Vanilla Top-1 | Predify t9 Top-1 | 差值 pp [95% CI] |
|---|---:|---:|---:|
| clean | 72.2% | 72.1% | −0.1 [−0.8, +0.6] |
| noise 0.25 | 58.8% | 60.4% | +1.6 [+0.5, +2.7] |
| noise 0.5 | 35.3% | 38.7% | +3.4 [+1.9, +5.0] |
| noise 0.75 | 14.8% | 18.1% | +3.3 [+2.0, +4.7] |
| noise 1.0 | 5.5% | 6.8% | +1.3 [+0.4, +2.3] |
| noise 2.0 | 0.7% | 0.7% | 0.0 [−0.3, +0.3] |
| occlusion 0.3 | 60.6% | 60.5% | −0.1 [−1.0, +0.8] |

noise 0.5 中，50 张由错变对、16 张由对变错，净多对 34 张；精确 McNemar 双侧 p≈0.0000333。noise 0.75 为 41 对 8，p≈0.00000196。它们在只考察 11 个 t9 条件的多重比较敏感性中也较稳健。完整结果见 [原始基准复核](vanilla_t9_raw_audit.csv)。这不是对全部时空搜索做过确认性校正，也尚未证明跨噪声种子泛化。

这组对比检验的是整个 Predify 系统，不能把收益单独归给 feedback、预测误差梯度或 memory。PCoder5 的校准选择 `ffm=0.4, fbm=0, erm=0`，且旧记录中与 `erm=0.01` 很接近，这使“时间平滑/状态保持贡献很大”成为有价值的消融假设，而非已定论的机制。

**3. 本次新增、最影响后续决策的发现：Same 优于 Different，并不代表有净收益。**

固定五分类读出在 FC2 t9 的绝对准确率：

| 退化 | 无记忆 | Hebbian Same / Different | PCoder carry Same / Different | 联合 Same / Different |
|---|---:|---:|---:|---:|
| noise 0.5 | 45.5% | 41.0% / 40.5% | 46.5% / 45.5% | 41.5% / 39.0% |
| occlusion 0.3 | 41.0% | 39.0% / 37.5% | 40.0% / 40.0% | 39.0% / 40.0% |

以旧报告最关注的 noise+联合 carrier 候选为例：

- Same−Different：+2.5 pp，CI [+0.5,+5.0]；5 个 Same-only correct、0 个 Different-only correct；exact p=0.0625。
- Same−无记忆：−4.0 pp，CI [−9.5,+1.5]；11 个改善、19 个损失；exact p≈0.2005。
- Different−无记忆：−6.5 pp，CI [−12.0,−1.0]；10 个改善、23 个损失；exact p≈0.0351，未经多重校正。

因此，更准确的解释是：**当前候选显示 Same 比不匹配的记忆状态表现更好，但没有证明它比没有记忆更好。** 结果与“异类记忆产生干扰，正确 prime 部分缓解干扰”相容；尚不足以确认这一解释，也不能断言 Same 本身必然有害。

这里的“无记忆”来自同一 carrier factorial 的 `none` 条件：仍呈现 previews，但不保留其 Hebbian/PCoder state。它不等同于根本不呈现 preview 的 target-only，也不等同于保留 carrier、呈现中性 prime。未来仍需这些更细的控制。

联合机制的交互按 `(S−D)联合 − (S−D)Hebbian − (S−D)PCoder` 计算，noise t9 为 +1.0 pp [−2.0,+4.0]，occlusion 为 −2.5 pp [−6.0,+1.0]。不能凭联合条件出现一个显著点、单独条件没有显著点，就声称协同。见 [交互分析](carrier_interaction.csv)。

**4. Clean recovery 是有用诊断，但也需要无记忆参照。**

旧结论中，Same 比 Different 更接近 clean reference 的结果可以复现。例如 PCoder5 t9 cosine：noise Hebbian-only 为 +0.00559；联合为 +0.00439。它说明 prime 内容确实调制了状态到 clean reference 的距离。

但新增无记忆比较显示，noise Hebbian Same−无记忆为 −0.03084 [−0.03412,−0.02749]，联合 Same−无记忆为 −0.03374 [−0.03707,−0.03029]。occlusion 下二者也约为 −0.019。因此，“Same 相对 Different 的恢复优势”不能升级为“记忆使状态比无记忆更接近 clean”。纯 PCoder carry 在 occlusion 的 PCoder5 上确实有小幅 Same−无记忆正值 +0.00060，但没有对应的 t9 分类增益。

这些是保存的 recovery 标量之间的对比。跨 carrier 的随机初始化调用次数可能不同；reference 是每个时间步演化中的 clean 分支，而非统一缓存的确定性终态。Same/Different 同一 carrier 的配对更直接，跨 carrier 的数值适合揭示解释缺口，不足以单独证明记忆破坏了语义信息。确认前应保存或复用统一 clean reference，配对固定随机初态，并同时报告固定 feedforward clean reference 与收敛 clean reference。

此外，PCoder5 校准确认文件里的 `all_deep_recovery_cells_pass=False`：occlusion PC5 cosine 的 CI 跨 0。应表述为“多数深层恢复指标通过，遮挡顶部方向恢复仍不确定”。“分类没有显著变差”也不是已经证明非劣效，需要预设可接受损失界限并据此检验。

完整新增数值见 [recovery 基线对比](recovery_baseline_contrasts.csv)。目前更值得研究的机制问题是：**为何某些记忆使 Same 相对 Different 更好，却同时使两者偏离无记忆状态，且这些位移未被固定分类器利用？**

**5. Sharpening、可解码性与读出收益应继续分开。**

旧 full-image/half-field 实验的“complete sharpening”是三个效应符号同时满足：激活下降、归一化类内方差下降、归一化 Fisher 上升。代码没有为该标记要求三个统计区间同时通过。特别是 Conv4 某些方差效应只有约 0.006%～0.009%，不能称为已经稳定复现的强效应。

paper clean 阶段的 Conv4 t0 one-back 解码为 +2.5 pp，但激活下降的 CI 跨 0；没有一个点满足严格联合判据。degraded carrier 阶段的 FC2 t2/t3/t4 有探索性的 suppression+decoding 同点效应，但固定读出在对应端点没有复制这些优势。

这一区别有研究价值：每个条件分别训练 SVM，回答“该条件下类别信息能否被一个适应它的线性边界提取”；冻结同一个 SVM，回答“既定边界能否利用变化”。前者不是错误分析，后者也不是唯一神经科学端点，但二者不能互相代替。目前“主要瓶颈就是 readout mismatch”仍属假说，竞争解释包括记忆引入的无关方向位移、类别偏置、抑制损伤及小样本读出不稳定。

固定读出全部 240 个单元中，旧 bootstrap 下界为正的有 26 个；精确双侧 p<0.05 的有 16 个；以这 240 个检验作为探索性家族做 BH 校正后，q<0.05 的为 0，最小 q≈0.1853。这不证明所有效应为零，但说明不能从这个搜索图里选择点后按单次检验宣称成功。详见 [多重比较复核](fixed_head_multiplicity_audit.csv)。

**6. 现有设计还需补齐的边界。**

| 问题 | 为什么影响结论 | 后续处理 |
|---|---|---|
| Same 同图、Different 异大类 | 实例重复、类别提示、干扰同时变化 | 增加同 synset 不同图片、同大类不同 synset，以及无记忆/中性控制 |
| 读出训练与测试有 72 个 synset 重叠 | 已实现跨图片，未实现完全跨 synset | 明确两种泛化目标；检验未见类别实例时使用 synset-disjoint 划分 |
| 植物大类只有 7 个映射 synset | 40 张图不等于 40 个独立语义类别；类别层面的 CI 可能过窄 | 先盘点可用 synset/图片，再设计类别分层抽样或扩展数据集 |
| 全部 paper noise target 使用 seed=0 噪声 realization | 结果对单一噪声模式的依赖未被评估 | 新噪声种子按 target 配对；同图的多个噪声版本不能当独立图片 |
| grouped CV 后仅对 correctness 做图片 bootstrap | 未包含重训读出器和 CV 划分的不确定性 | 独立测试集为主；补充 synset 聚类 bootstrap 或包含重拟合的置换/重采样 |
| 每个层、时刻分别拟合固定 head | 同一时刻的条件比较有效，跨时刻准确率还混入 head 差异 | 研究时间积累时另用共同读出器或交叉时间泛化矩阵 |
| 15% canvas object 约 34×34 像素 | 原 1000 类 head 严重失配；noise 又在缩放前加入 | 将小对象五分类与全图 ImageNet 分类分开；不要直接横比两条协议的 noise 0.5 |
| random_init=true 的 t0 | 不是纯前馈起点，早期效应可能依赖初始化 | 补充 random_init=false 的相同流程及统一初态控制 |

读出训练/测试图片零重叠已从原始文件复核，这是现有设计的优点。synset 重叠本身不使跨图片测试失效；它限制的是“未见 synset 泛化”的主张。VGG 主干已经在 ImageNet 预训练，因此即便后续读出做到 synset-disjoint，也不应说整个网络从未见过这些类别。

另一个数值口径修正：no-Hebb 的 no-prime 与 one-back 保存数组完全相同，但 two-back 相对 no-prime 的 logits 最大绝对差为 0.0007875，保存的 float16 FC 特征最大差为 0.001953125；Top-1/Top-5 逐样本正确性完全相同。不能把三条件写成“逐元素完全一致”。这些小差异的来源本次未追溯到运行时，应在下次实现验收时记录确定性设置并复查。详见 [no-Hebb 数值审计](clean_nohebb_numerical_audit.csv)。

**7. 建议按信息价值安排下一步。**

| 优先级 | 实验/分析 | 主要回答什么 | 继续或停止的依据 |
|---|---|---|---|
| P0 | 补齐基线和可复现对照 | 收益、干扰、类别提示分别有多大 | 固定 target、noise、初态、clean reference；先完成小规模实现验收 |
| P1 | 记忆内容与强度消融 | 同图特异性在哪里，Hebbian 抑制是否带来代价 | 预留确认集；在机制 pilot 上检查 Same−无记忆及同类控制，而非只最大化 Same−Different |
| P1 | 冻结读出下的位移分解 | 恢复方向为何没有变为正确决策 | 将 Δfeature 投影到 true-vs-competitor margin 方向；报告错→对和对→错、类别混淆 |
| P2 | 独立样本、独立噪声的单一端点确认 | 候选能否泛化、是否有实用净收益 | 工程主张要求 Same 同时优于 Different 与无记忆，并有预先声明的最小有用效应 |
| P2 | 提前读出/时间积累 | priming 是否主要改变处理速度 | 独立验证集选择共同 head、窗口或停止规则；在新测试集上比较等计算成本 |
| P3 | 跨稀疏度/数据集迁移、decoder 改造 | 稀疏性和生成目标能否改善机制 | 先有清晰、可复现的主对比，再扩展，避免同时改变太多部件 |

P0/P1 建议以 noise 0.5 为主、occlusion 0.3 为机制边界，不再铺开所有退化强度。prime 条件至少包含：同图、同 synset 不同图、同大类不同 synset、异大类；另设无记忆条件。一个小规模筛查可保留 Hebbian-only、PCoder-only、联合三种 carrier。它用于分离解释，不能作为新一轮显著点搜索后直接宣布确认。

记忆强度消融应把 channel boost 与 inhibition 分开，检验零/较弱/当前调制；使用 clean accuracy、类别均衡准确率及 Same−无记忆的最小损失约束。若 Hebbian recovery 的相对优势仍伴随绝对损失，优先测试较弱调制、按相似度门控或随时间衰减，而不是无约束地增大 Hebbian 系数。所有调参在独立 pilot 上完成。

读出位移分解可以先利用现存保存的特征和分类器完成，不需要重新跑 GPU：计算同一分类器下正确类别相对竞争类别的 margin 变化，区分有用方向与分类器不敏感方向的位移，检查它与 recovery、激活变化的关系。相关性只能定位，随后再以层级/抑制消融验证因果。

确认实验不应直接照搬“至少 1000 张”的旧建议。先估计配对差的 discordant rate，再针对最小有用效应做功效模拟，同时考虑 synset 和重复噪声的聚类。以独立图片、正态近似为例，检测 2 pp、80% power、双侧 0.05，若 discordant rate 为 5%～15%，所需数量大约 1000～3000；这只是计划量级，不是当前设计的精确样本量。当前植物类只有 7 个 synset，必须先解决严格新样本及 synset-disjoint 的容量问题。

如果目标偏神经机制，主终点可以是预指定时间窗内、同点 suppression+decoding 的复制及其对内容/间隔的依赖，不必强制要求原始 ImageNet head 提升。如果目标偏鲁棒识别，主终点应直接设为固定读出相对无记忆的净增益及计算成本。两个方向可以共享模型，但应各自有成功标准。

稀疏化值得作为后续机制检验：比较 `[(Same−baseline)稀疏 − (Same−baseline)dense]`，并同步约束绝对性能、活跃单元数和表征维度。只增加零激活或降低总体幅值不构成更有效的 sharpening。THINGS 等跨数据集验证同样有价值，但应先固定当前最有解释力的对比，避免把数据、读出器和模型同时换掉后难以归因。

**8. 暂时不建议投入的方向。**

- 继续以 noise 2.0 或原始小对象 1000-way head 寻找 priming 显著点：地板效应下难以回答目标问题。
- 扩展全量层×时间×强度搜索，再选最好的点作为成果：现有多重比较审计已显示风险。
- 把降低 activation、原始 variance 或内部 prediction error 单独当成功：它们都可能与任务损失共存。
- 直接升级更大 decoder：目前还未排除记忆干扰和读出方向失配；换架构会同时改变容量、训练目标与动力学。
- 把现有联合 carrier 的 +2.5 pp 写成已确认的终端收益，或写成两种记忆协同：基线与交互证据均不支持这种强度的表述。

当前适合形成的研究叙事是：**递归推理可改善中等噪声识别；跨呈现记忆改变表征和时间过程，但局部 sharpening、相对 clean recovery 与固定决策收益存在可测量的分离。** 后续最有价值的工作，是解释这种分离、识别记忆何时有利何时干扰，并在预先固定的对比中验证。

已有综述的开头虽标注了后续实验完成，但其正文仍把 clean-reference、carrier 和共享读出列为未来工作。本报告将这些视为已经完成的探索阶段，建议不再重复旧路线图。
