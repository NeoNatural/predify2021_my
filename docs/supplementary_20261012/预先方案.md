# 读出、初始化与等预算内容对照（2026-10-12）

本轮执行用户要求的三点，不更改主干、Hebbian 参数或 PCoder 增益。旧 B/D、旧 readout 训练图和旧 paper/全图 target 均不进入新训练、开发、测试 target。划分预先固定为训练 200、开发 100、测试 100，五类平衡；新测试额外排除旧补充 B/D 的所有 preview。训练/开发图片可能曾作为旧 preview 出现，但不曾作为旧 target 或 readout 训练图。仅承诺图片隔离，不声称 synset 隔离；主干此前已在 ImageNet 预训练。

只有训练集拟合共同读出；开发集估计时间分数尺度；测试在权重、尺度、端点及对比冻结后才运行。旧确认 D 不进入本轮选择。本轮样本量用于诊断及小规模独立检验，不足以排除 2 pp 小效应。

读出比较：原先 noise/FC2/t9 StandardScaler+LinearSVC 保持不变；新共同 StandardScaler+LinearSVC(C=1) 使用训练图片的随机初始化无记忆、前馈初始化无记忆、中性 PCoder carry，全部 t0–t14 和三个噪声版本。各图片/条件/时刻均匀贡献，不训练主干。初始 max_iter=50000；若未收敛，仅提高迭代上限，不选择 C 或测试性能。

分数校准：开发集每个时刻上，汇总七个条件与图片的五类分数标准差，取中位数作为该时刻的尺度。条件间共用尺度，两个读出分别校准。尺度冻结后只用于 t0–t3 分数平均；单时刻 argmax 不变。原始与校准后的早期平均均报告，不能用测试选择其一。

训练开始后、读出拟合和开发/测试提取之前增加一个次级配对对照：matched_t9 使用同一批新训练图片、三个训练条件和三个噪声版本，仅训练 t9。它用于区分新训练图片/条件与时间覆盖的影响，不替代预先指定的 pooled 主读出。三个读出分别估计开发集时间尺度。中性条件只移除一个 slot；其余 distractor 仍排除 target 大类，不能视为完全没有类别信息的刺激。

条件：random-init target-only、feedforward-init target-only；PCoder carry 的 exact / same_synset / same_category / different_category / neutral。前两项是高效无记忆基线：不花费计算处理不会保留的 previews。验收中另执行有相同 previews 但 reset 的条件，要求输出与对应 target-only 逐元素相同。前馈初始化是 random_init=false 的 Predify 状态初始化，不等同于另一个独立 torchvision vanilla 系统。

每条 target 保存 15 个状态，previews 各 2 步。用 backbone hook 实测全部主干调用数，包括初始化与两个 previews：carry 的前缀 5 次；target-only random 首个返回状态 2 次；target-only feedforward 首个状态 1 次。

主端点：共同读出，累计 9 次主干调用的单状态分类。此时 carry 为 t3、随机无记忆为 t7、前馈无记忆为 t8。主要比较 exact 对前馈无记忆、同 synset 不同图、异大类。对三个主比较报告图片簇双侧符号置换 p、Holm 校正 p、图片簇 bootstrap CI；有利记忆和精确重复是分开的主张。t9 同步状态与总预算 15（carry t9、随机无记忆 t13、前馈无记忆 t14）是次级诊断；原 t0–t3 平均属于机制诊断。

三个新噪声版本以图片为簇；噪声 seed 在图片间变化，初始化 seed 与噪声版本分离，同一图片固定。报告图片簇和 synset 簇区间、逐噪声效果、绝对准确率、类别混淆、margin 和分数尺度。

开发提取期间、冻结和测试之前补充诊断端点：相同 target 主干调用数 4 和 10。它们不计入 preview 的 5 次调用，用于区分 target 出现后的计算与总计算；属于次级端点，不改变总预算 9 的主检验。

相等主干调用是固定架构下的计算代理，不宣称精确 FLOPs 或端到端时延相等。保存包括 preview 的累计耗时，但包含特征保存/同步等诊断开销，不当作部署速度。旧 early improvement 是否主要依赖随机冷启动，由前馈初始化基线与等预算对比回答。
