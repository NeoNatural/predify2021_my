方法与核对

目标、预览顺序、训练完成的三个检查点和原验证集定标全部配对复用。有 carry 取自原全程缓存。无 carry 在第二帧结束、短时记忆完成两次写入并冻结之后，仅恢复五层 PCoder 的表征、预测、误差梯度与预测误差。逐批核对了全部恢复张量、四层记忆的写入次数和冻结状态、重置前后记忆张量的标识和版本，以及送入熟悉度回路的两帧预览特征与原缓存逐值一致。这项对照估计恢复初态对整套回路的影响，包含它通过目标反应改变门值的间接影响。

早期为 0–4 步，中期 5–9 步，晚期 10–14 步。先在每个种子每步求同图对指定对照的效应，再平均种子和时间步。Fisher 是按长度归一化后的 FC2 群体活动所算的类间散度 / 类内散度。固定分类器沿用独立训练的线性 SVM；逐步 MVPA 采用相同的六折、各大类每折留出一整个概念，只在折内训练分类器和标准化，不参与回路选择。宏 AUC 衡量类别排序，平衡准确率（BA）是各大类正确率的平均。

区间来自 4,000 次各大类内配对概念块重采样，两组、三种预览、三个种子和所有时间步共用抽样。窗口统计量在每次重采样内重新计算；曲线色带为逐点区间。表中的分项不能解释为 carry 与 Hebbian 记忆各自独立相加的因果份额。
