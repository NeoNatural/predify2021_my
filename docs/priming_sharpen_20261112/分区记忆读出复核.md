# 分区记忆读出的 fold 3 缓存复核

使用既有 t9 Conv5 缓存，ImageNet 32 张、THINGS 40 张。原 512→64 编码、长期连接、群体归一化和四层轨迹均固定。推理输入只有两帧 preview 与 target 特征。槽位不参与计算。统计使用样本的类别和概念，按类别内概念块配对重采样 4,000 次。

Conv5 网格固定按列分成左右两个 14×7 区域，各自用原规则和 0.5 衰减写入两次。target 全图分别读取左右矩阵。平均和竞争组共用这对矩阵，分别取两个读出分数的均值和最大值。全图组沿用原矩阵。左右矩阵的算术平均复现全图矩阵，最大绝对误差为 `1.49e−7`。读出最大误差为 `1.19e−7`。清空时各组分数归零。

## 两帧与左右分区的追加复核

复用同一批 fold 3 的 72 张 t9 Conv5 轨迹和原编码器。原两侧矩阵为 `A_s = 0.5 B_{1,s} + B_{2,s}`。四路各自保留 `B_{1,s}` 与 `2 B_{2,s}`，同侧均值逐元素复现原矩阵。读取时对每个矩阵使用同一份 target 特征。比较两侧平均、两侧取最大、四路平均、四路取最大，以及四路读取后每侧先平均两帧再左右取最大。最后一项保留两个竞争候选。槽位只属于原刺激设计，推理不读取槽位。原两侧 AUC 点估计和区间完整复现，清空矩阵得零分。
