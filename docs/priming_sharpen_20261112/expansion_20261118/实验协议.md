# 8× 熟悉度回路的等预算扩样与增强实验

沿用 PCoder4、PCoder5、FC1 和 FC2 的串联轨迹及既有熟悉度回路。在两套数据内分别比较五组，沿用三个配对训练种子 2026111301–2026111303。

| 条件 | 训练时的变化 | THINGS 照片 | ImageNet 照片 |
|---|---|---:|---:|
| A | 8× 可训练编码器基线 | 640 | 512 |
| B | 每个大类新增 1 个概念，每个新概念 8 张照片 | 680 | 544 |
| C | 每个大类从 8 个既有概念各补 1 张第 9 张照片 | 680 | 544 |
| D | 仅移动第二帧中被替换的预览物体 | 640 | 512 |
| E | 仅改变第二帧中被替换的预览物体的对比度 | 640 | 512 |

B、C 沿用 A 的全部图像和原配对试次。新增试次逐一配平侧别、对比度、背景和异类预览图。用图像索引及 SHA-256 排查与本轮验证、测试及其他新增照片的重叠。THINGS 的 B 组新增植物概念为蕨类（fern），对应 8 张照片曾用于历史批次。其余新增照片未出现在所核对的历史清单。

D、E 对每个目标预先固定两个增强版本。每次抽到该目标时，从原版和两个增强版本中等概率选择。同图、同概念异图和异类试次共用当次扰动。D 的垂直位移不超过 8 像素。水平位移范围为左槽 −5 至 +8 像素，右槽 −8 至 +5 像素，两侧都因画布边界略向内偏。E 从原有对比度范围 [0.4, 0.6] 连续取值。物体保持原尺寸，中央目标、第一帧和第二帧的另一物体沿用原画面。

## 检查点和统计

- 每组 THINGS 更新 1,600 步，ImageNet 更新 1,280 步。批大小 8，同一数据集每 80 或 64 步验证一次，各检查 20 次。各组都取最低验证损失的检查点。A 复用原检查点和逐轮日志，其缓存及训练预算均已核对。
- 主要指标为同图对同概念异图的定标前熟悉度 AUC。训练侧统一在 A 的原试次上测量。训练和验证时，三个历史共用同图条件的第 9 步目标反应。冻结检查点后，旧测试和新留出用各历史自身的第 9 步目标反应。
- AUC 按大类、类内概念等权。每个种子先做配对差，再对种子取均值。每类内对概念块做 4,000 次配对重采样，报告百分位 95% 区间。训练与验证概念互斥，计算两者差距时分别重采样。
- 新留出在训练前锁定，共 THINGS 103 张、ImageNet 96 张。入选照片跟训练、验证、旧测试和已登记历史刺激按哈希隔离。与本轮训练和验证概念互斥。部分概念曾在历史批次出现，其中 THINGS 植物的 2 个概念都来自旧测试概念，使用额外照片。
- FC2 复核的入选条件是相对 A 的验证 AUC 点估计为正，且新留出原生目标反应的 AUC 增量 95% 区间下限为正。沿用原仅目标定方向的算子、验证集门值定标、固定分类读出及抑制预算。

## 复现

在工程根目录使用现有 predify2021 环境。按下列顺序先执行 THINGS，再把前四条命令中的 things 换成 imagenet。特征提取需要 CUDA 和原工程的四层校准与固定读出文件。

```powershell
python -B analysis/priming_familiarity_expansion_collect_20261118.py things fit
python -B analysis/priming_familiarity_expansion_fit_20261118.py things fit
python -B analysis/priming_familiarity_expansion_collect_20261118.py things test
python -B analysis/priming_familiarity_expansion_fit_20261118.py things test
python -B analysis/priming_familiarity_expansion_report_20261118.py
python -B analysis/priming_familiarity_expansion_report_20261118.py --query-check
python -B analysis/priming_familiarity_expansion_fc2_20261118.py things
python -B analysis/priming_familiarity_expansion_fc2_20261118.py imagenet
```
