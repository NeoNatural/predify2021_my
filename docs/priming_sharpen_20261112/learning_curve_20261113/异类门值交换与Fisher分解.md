# 异类门值交换与 Fisher 分解

在固定冻结组 Exact 门的条件下，逐 target 换入可训练组的异类门，THINGS 的 Exact 对异类 Fisher 增益恢复 **2.54 个百分点［0.26，4.48］**，ImageNet 恢复 **4.28 个百分点［1.36，5.83］**。反向交换使可训练组分别损失 **2.54［0.27，4.41］** 和 **4.22［1.33，5.71］** 个百分点。把冻结组异类门的均值降到可训练组水平，解释了大部分异类门效应。保均值压顶和类内保分布置换的结果未显示稳定的独立饱和或逐 target 分配效应。

## 缓存与统计

使用 THINGS 108 张／30 概念和 ImageNet 96 张／24 概念的既有测试缓存，复用三个固定种子 2026111301–03 和原验证集阈值、斜率。各历史使用自身原生 t9 特征。每个交换或对照中，保持该组 Exact 门、四层轨迹、仅 target 定方向、0.45 形状混合上限和 0.003 抑制预算。固定 SVM 无需用于 Fisher 计算。运行只读已有模型分数和特征缓存，未重跑任何图像前向或训练模型。

点估计先在每个种子上计算，再取三种子均值。配对 95% 区间沿用 4,000 次类别内概念块重采样，同一抽样用于各门、历史和种子。等均值操作在完整缓存上按原类别和概念权重设定，重采样中沿用同一干预。置换的效应先在每次重采样内对置换取均值，区间反映概念抽样。原生绝对散度、Fisher、异类门值统计和历史 Fisher 差的逐种子点估计与区间均复现上轮结果。沿用的百分位区间可能偏离原样本点估计，例如 ImageNet 的等均值效应。当前测试批量已查看，这些结果用于机制复核。

## 绝对 Fisher 分解与双向交换

令 `H(e,d) = 100 × (Fisher_Exact(e) / Fisher_异类(d) − 1)`，其中 `e` 和 `d` 分别指定 Exact 门与异类门的来源。用两种替换顺序的平均分解冻结减可训练的历史增益变化。Exact 贡献为两种异类门下换入冻结组 Exact 门的平均效应。异类贡献为两种 Exact 门下换入冻结组异类门的平均效应。两项逐种子、逐重采样严格加和为净变化。

| 数据集 | Exact 绝对 Fisher，可训练 → 冻结 | 异类绝对 Fisher，可训练 → 冻结 | 历史增益净变化（pp） | Exact 贡献（pp） | 异类贡献（pp） |
|---|---:|---:|---:|---:|---:|
| THINGS | 0.286580 → 0.287142 | 0.262617 → 0.268866 | −2.33［−3.39，−0.51］ | +0.21［−1.70，+2.42］ | −2.54［−4.45，−0.26］ |
| ImageNet | 0.195457 → 0.196209 | 0.175543 → 0.182475 | −3.83［−4.32，−1.60］ | +0.42［−1.42，+2.35］ | −4.25［−5.77，−1.35］ |

两套数据中，冻结组 Exact 绝对 Fisher 点估计略高，部分抵消异类绝对 Fisher 升高带来的历史增益缩小。这里的双向交换逐 target 复用同一异类特征和方向，因此交换后异类 Fisher 与门的来源组一致。交换检验了整条门值向量对固定 FC2 算子的作用。

| 数据集 | 固定的 Exact 门 | 异类门替换 | 替换前 → 后的 Fisher 增益 | 替换效应（pp） |
|---|---|---|---:|---:|
| THINGS | 冻结 | 冻结 → 可训练 | 6.80% → 9.33% | +2.54［+0.26，+4.48］ |
| THINGS | 可训练 | 可训练 → 冻结 | 9.13% → 6.59% | −2.54［−4.41，−0.27］ |
| ImageNet | 冻结 | 冻结 → 可训练 | 7.53% → 11.80% | +4.28［+1.36，+5.83］ |
| ImageNet | 可训练 | 可训练 → 冻结 | 11.36% → 7.14% | −4.22［−5.71，−1.33］ |

六个数据集与种子组合的双向交换方向一致。THINGS 的第三个种子原始净差为 +0.72 个百分点，仍出现异类门交换后恢复 +2.09 个百分点的结果。该种子的 Exact 贡献抵消了异类贡献。

## 整体强度、饱和和分配

1. 两组异类门分别压顶到 0.95，按同一比例放大正门后截断，以保留原加权均值、触发集合和大致排序。原始精确饱和率由 THINGS 的 18.61%／33.33%、ImageNet 的 31.94%／44.44% 降为零。这一步也重分配了近顶门值，检验的是这项保持均值的压顶干预。
2. 把压顶后的冻结组正门等比例缩小到可训练组的加权均值，每个种子单独匹配。两组平均门分别统一为 THINGS 0.334、ImageNet 0.491。该缩放保持冻结组的触发集合和排序，并降低高门幅度。
3. 在类别内做 256 次固定随机置换，同一种子内各条件共用相同置换。每次保持该类完整的门值分布、触发率和饱和率，并打散门值与类内 target 的配对。置换后的差值反映保留下来的类条件分布，原配对与置换均值的差反映类内 target 分配。类别之间的门值分配仍保留。

下表用冻结减可训练的符号。压顶项、均值项和等均值残余之和为异类总贡献。分布项和分配项之和为等均值残余。历史增益在两种固定 Exact 门下取平均。

| 对照及贡献（pp） | THINGS | ImageNet |
|---|---:|---:|
| 异类总贡献 | −2.54［−4.45，−0.26］ | −4.25［−5.77，−1.35］ |
| 0.95 压顶项，保持各组原均值 | +0.08［−0.08，+0.23］ | +0.16［−0.12，+0.37］ |
| 整体均值项，压顶后缩放 | −2.10［−2.40，−1.01］ | −2.87［−2.76，−1.77］ |
| 等均值后的残余 | −0.52［−2.26，+0.98］ | −1.54［−3.26，+0.56］ |
| 残余中的分布项 | −0.46［−0.85，+0.03］ | −0.59［−0.77，−0.19］ |
| 残余中的类内 target 分配项 | −0.05［−1.69，+1.33］ | −0.95［−2.76，+1.03］ |

按点估计，这条干预路径下的整体强度约占异类总贡献的 83%（THINGS）和 68%（ImageNet）。原生门直接置换后，异类贡献仍为 −2.62［−2.89，−1.35］和 −3.42［−3.23，−2.15］个百分点。ImageNet 在等均值后仍有约 0.59 个百分点的类条件分布效应，保留的分布包含触发比例和正门幅度。两套数据的类内 target 分配区间均含零。

在两组已经等均值的条件下，再把上限降到 0.80 并保持均值和各自触发集合。相对 0.95 对照，等均值残余改变 +0.18［−0.04，+0.41］（THINGS）和 −0.34［−0.72，+0.19］（ImageNet）个百分点。压顶项和均值项的数值依赖选定的干预路径，饱和结论限于这两种压顶方式。
