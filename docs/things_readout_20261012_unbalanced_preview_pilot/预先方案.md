# THINGS 上的读出、初始化与等预算复现

本方案在 THINGS 模型提取、读出拟合和测试分析之前记录。目标是重复 2026-10-12 的最新规范实验：检查时间读出与初始化，区分同图内容、类别一致性和一般预热，并计入全部预览开销。本轮只运行 noise 0.5，不恢复旧 THINGS 的全尺寸、Hebbian × Prime 扫描，不增跑遮挡强度。

## 数据与必要的任务范围调整

数据来自引用任务所在目录 `C:/Users/liang/Documents/ChatGPT/THINGS数据集测试predify_my/data/THINGS`。复用其经过本地验证的元数据解析器：1854 个概念、26107 张图片，334 个概念与 ImageNet-1k WordNet ID 严格等值映射。沿用文件来源过滤，不使用名称模糊匹配或上位词扩展。新 target 排除旧 THINGS 1000 张 cohort 图片及文件字节重复；明确 ImageNet 来源的图片在 target 和 preview 中均排除。来源不明数量单独记录。这不证明图片与所有预训练网络数据绝无重叠。

保持原五类映射时，植物只有 acorn、daisy 两个精确交集，共 24 张非 ImageNet 来源图片，排除旧 cohort 后仅 14 张，无法复现五类的 40/20/20 张划分。因此采用四类平衡方案，避免放宽映射或以极少植物样本承载五类结论。用户已授权按合理方法调整设计；四类方案在任何开发/测试结果产生前确定。

正式目标类别为 animals、clothing、food、vehicles，各训练 40、开发 20、测试 20 张，共 160/80/80 张。各集合按概念轮转采样，尽量分散概念；每个概念预留一张 preview 候选，所有 320 张新 target 都禁止用作其他 trial 的 preview。划分按图片和文件哈希隔离，不要求概念互斥。同 synset 不同图对应同一个精确映射的 THINGS native concept；两种标签都保存。

为了保持原来的两个双图 preview，仍从完整五类候选池中各取一个非 target 大类干扰物，其中允许植物作为干扰物。所有预览内容条件使用相同基础干扰流。植物不进入四类分类候选集合。未知来源、历史重叠和字节重复数写入划分审计。

## 与上一轮一致的实验规范

- 模型、torchvision 原始 VGG16 FC、PCoder 权重、PCoder 增益和固定层处理均来自当前主项目，与 ImageNet 最新实验一致。关闭 Hebbian 动态更新。
- torchvision IMAGENET1K_V1 预处理；对象比例 0.15、水平偏移 0.175、背景 0.5；噪声加在标准化物体张量后再构造画布。
- 七条件：随机无记忆、前馈无记忆、同图 carry、同概念不同图 carry、同大类不同概念 carry、异大类 carry、中性 slot carry。中性不等于完全没有类别信息。
- 两个 preview 各 2 步，target 保存 15 步；随机初始化和噪声 seed 分离，噪声 realization 在图片间变化。三个训练/开发/测试噪声基种子分别为 1201–1203、1211–1213、1221–1223；新的全局 seed 为 20261013。
- 训练仅使用随机无记忆、前馈无记忆、中性 carry；160×3×3=1440 个训练序列。开发和测试各 80×3×7=1680 个序列，合计 4800 个正式序列。
- 无记忆 target-only 省去不会保留的预览。smoke 中验证处理预览后 reset 与 target-only 的 logits/FC2 逐元素相同。
- 主干 forward hook 实测总调用数：carry 为 6–20，随机无记忆为 2–16，前馈无记忆为 1–15。

## 读出、冻结与主检验

主读出 pooled 是 THINGS 训练集所有 t0–t14 状态的共同 StandardScaler + LinearSVC(C=1)；次级 matched_t9 使用相同图片、条件和噪声，仅拟合 t9。不得依据开发或测试的准确率改变 C 或选择主读出。初始 max_iter=50000，仅未收敛时升至 200000。

保留两个固定权重的 ImageNet 迁移读出：原 legacy t9，以及上一轮已经冻结的 imagenet_pooled。它们都只保留动物、衣物、食物、车辆四列决策分数，不重训权重。这是预定四类任务的候选集限制，并不代表原五类准确率。后者仅用于区分已有共同读出的跨数据集迁移与在 THINGS 上重新拟合，属于次级检查。

每个读出的时间尺度只用 THINGS 开发集计算：每个时刻汇总七条件的类间分数标准差，取中位数；所有条件共用尺度，最低 1e-6。只用于 t0–t3 平均，不改变单状态 argmax。这不是概率校准。全部读出、尺度、方案和数据清单的哈希在测试提取前冻结。

预定主端点：THINGS pooled，总计 9 次主干调用；对应 carry t3、随机无记忆 t7、前馈无记忆 t8。三项主要对比为同图减去：前馈无记忆、同概念不同图、异大类。20,000 次图片簇 bootstrap、图片簇双侧符号置换和 Holm 三项校正；以图片为独立单位，不把噪声数算入样本量。另报告概念/synset 簇敏感性区间和逐噪声差值。边际 percentile CI 不作为替代校正检验的显著性规则。

次级诊断包括总预算 15、target 调用预算 4/10、t0/t1/t3/t9、原始与校正 t0–t3 平均、初始化对比、跨读出对比、类别混淆、margin 和分数尺度。所有端点统一报告，不在测试集上挑最佳时间点。总主干调用仅为计算代理，不宣称精确 FLOPs 或部署时延相等。

训练提取期间、开发/测试提取前补充描述性参照：利用已保存的上一轮 ImageNet 测试分数，仅保留相同四类 target 和四列候选分数，以同一冻结 legacy / ImageNet pooled 权重比较两套数据的 t0/t3/t9 及总预算 9/15。无需新提取，不重新拟合或选择端点；不把未配对的概念组成差异解释成纯数据集因果效应。

## 验证及解释

先运行覆盖四类的 smoke 及数据适配测试，再完成训练、拟合、开发、冻结，最后运行预留测试。数据、映射、代码、依赖、模型与读出哈希均保存；原 ImageNet 实验与引用 THINGS 历史结果保持独立目录。

这是对最新机制与统计规范的四类跨数据集复现，不是原五类结果的精确重演，也不是全部 THINGS 概念的分类 benchmark。不能直接把它与 ImageNet 五类绝对准确率比较后归因为数据集难度。测试仅 80 张、概念可跨集合出现；结果应报告不确定性，不根据测试追加样本直到显著。
