## 1. 当前结果应以哪一版为准

主版本是 `docs/tripartite_filtered_cv_20261027/实验结果.md`，最新绘图版本是同目录的 `自适应坐标与三种记忆图册.md`。此前在本聊天中说“新计划尚未执行”、沿用未交叉验证t9结果的说法已过时。

新版已经完成6,144条轨迹、92,160个target状态、3,620次SVM拟合，保存的总审计通过，测试记录报告81项通过。每数据集仍是64张目标、32个概念、四类。它复用了已查看目标，因此是新版处理下的探索性重复测量，不是新增独立确认。

已经落实：灰屏完整快照持久化与深拷贝；单一Hebbian强度；三种记忆各自内部比较；四种内容、无neutral；中央抗混叠；外周额外高斯模糊与对比度0.5；clean/noisy；五折概念分组；目标及所有预览概念跨折隔离；accuracy和macro OVR ROC-AUC；四层全特征图sharpening和双路径激活。

本轮噪声σ=0.5作用于224物体低通前，降采样后SD约0.122，不能再称为最终刺激承受σ=0.5的高噪声。clean/noisy分别训练读出，两组绝对accuracy不能作为同一分类器的抗噪差异。

同概念和同类别也出现早期正差值。例如THINGS noisy的Joint中，同概念对基线早期ΔACC为+6.42 pp，Exact为+4.42 pp；这是描述性观察，不是两者差异的统计检验。当前不能宣称精确重复优于语义一致性。早期t9表现属于时间泛化，不等于逐时间点可解码信息总量，也不能排除预览类别信息残留对目标分类的贡献。不同内容的计算流程相同有助于识别内容效应，但未证明包含preview开销的总计算效率提高。

### 2.2 尚未建立稳定终态识别收益，也未建立完整sharpening链条

固定t9的Exact差值在12个数据集×噪声×记忆组合中仅为0至+1.25 pp，AUC方向不一致。当前分类结果没有包含分类器重新拟合的置换或概念bootstrap推断，不能据小正值、曲线分离或折SD宣称显著。

FC2固定t9的Exact normalized trace变化在两数据集、两噪声、三种记忆中都为正，而不是预期的类内收缩。Hebbian/Joint的Same-category往往有更高normalized Fisher，但单一Fisher改善不能替代“激活下降、类内离散度下降、类别可分性提高”的联合证据。各层和早期窗口仍需保留，不能将FC2/t9概括为整个网络无效。表征CI是边际概念簇bootstrap区间，没有跨层、时间、指标的同时校正。

### 2.3 激活均值重叠不是已发现的记录错误

保存审计显示逐图重算和汇总一致，完整FC2轨迹不相同，Hebbian记忆非零。相对各自基线的最大组均值变化约0.46%–1.78%；逐图正负变化存在抵消。因此“平均激活近似相同”不等于“完整向量相同”，也不等于“机制已经生效到可提高分类”。自适应轴和局部放大只改善展示，不能提高证据强度。

### 2.4 MVPA波动仍需重视

逐时刻、逐条件独立拟合边界回答的是该条件表征可被怎样解码；共同t9头回答的是固定边界的跨时间读取，二者不能互换。目前五折测试大小16/16/16/8/8，最小折每类只有1个概念、2张图；同一图的噪声重复并不增加独立概念。高维读出、小测试集及边界变化均可能参与波动，不能仅凭波动认定MVPA实现有错。更有价值的下一步是扩大独立概念并平衡各折，保留MVPA但不按其峰值选设计。

## 3. 人类实验采用几类：优先匹配直接研究

本次是有针对性的原始论文检索，不是统计全部MVPA论文的系统综述，不能声称存在统一的“标准类别数”。所查相近研究有3、4、5类；分类任务层级和评分方式比数字本身更重要。

| 原始研究 | 刺激类别 | 实际解码方式 | 对本项目的意义 |
|---|---|---|---|
| Wynn、Bezsudnova、Jensen，2026，parafoveal priming/sharpening | 动物、服饰、食物、植物、车辆，5类 | 逐时间点线性SVM，五折，OVR AUC后平均 | 与本项目直接相关，优先匹配五类 |
| Fakche等，2024，自由观看与外周预览 | animal、food、object，3类 | 三对二分类AUC平均，十折；另有时间泛化 | 不是“三分类accuracy”，不能混淆机会水平 |
| Using High-Density EEG…，2022，物体识别 | bird、insect、tool、graspable object，4类 | 四分类及二分类对照，十折 | 支持少数预定类别的时间解码，并不要求类别越多越好 |

直接来源：[Wynn等正式接收版全文](https://www.nature.com/articles/s42003-026-10412-8_reference.pdf)、[Fakche等全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11622175/)、[四类HD-EEG研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9169880/)。

Wynn研究的刺激池为每类100对象、每对象15图，THINGS不足处补用其他图片来源，因此不能要求本地纯THINGS也达到同样数量。它的OVR构造使用某priming条件的正类、跨条件的其他类别负类；当前模型逐条件独立MVPA并非完全复刻。拟匹配时应在新方案中明确设置单独的论文对应分析，不能把旧macro OVR结果改名。其早期解码提高来自特定窗口分析，不能概括为全时间始终提高。

建议：主研究恢复动物、服饰、食物、植物、车辆五类；只扩大类内概念/图像，不因为全库支持更多类别而扩成十几类。五类ACC机会水平20%，二元OVR ROC-AUC机会水平仍为0.5。保持当前t9共同头作为模型功能读出；逐时间MVPA作为与人类研究更接近的表征分析，二者分别报告。

保留概念分组及完整视觉角色隔离，不为追求表面一致改成随机拆分相同图片的重复。针对类别泛化，[Grootswagers等教程](https://tijl.github.io/tijl-grootswagers-pdf/Grootswagers_et_al_-_2017_-_Decoding_Dynamic_Brain_Patterns_from_Evoked_Respon.pdf)强调按exemplar划分可避免对特定刺激的学习混入类别解码。人类研究有参与者层面的重复；单个网络中的五折、噪声种子不能充当参与者。网络step也没有经验证的毫秒换算。

## 4. THINGS重新盘点：解除ImageNet标签和概念匹配限制

### 4.1 可复现的候选规则

全量扫描26,107张本地图片、1,854个THINGS原生概念，按原生uniqueID分组，不加载ImageNet类别表，不要求两数据集配对。

主库存使用现有 `concepts-metadata_things.tsv` 的 `Top-down Category (manual selection)` 原生字段，按逗号分词读取。只接受在选定五类中归属唯一的概念；同时属于animal/food或plant/food的40个概念、552张原图暂放歧义清单，不能按有利结果任选类别。除此以外的原生副标签（如bird、dessert）保留记录。其余不含五类标签的16,563张图片不进入这五类候选。

排除明确ImageNet来源图；对非ImageNet图片做全库SHA-256去重。本次未发现额外字节重复，主五类池无来源未知记录。历史集合合并最初队列及所有能识别的THINGS实验manifest，包含目标、prime、distractor和最新filtered CV；原始队列文件有2,000条记录但只有1,000个独立图片，已去重。历史并集为2,205张图片、250个概念。

另外分别统计“Human Raters”和“WordNet”原生类别字段作为敏感性版本，不把三种口径的并集当作主库存。这里WordNet类别字段是THINGS自身的上位类别，不是精确ImageNet-1K映射。THINGS原始数据库确实提供多种类别标注，标注口径会影响数量：[数据库原始论文](https://pmc.ncbi.nlm.nih.gov/articles/6793944/)。

还需检查plant/tree/flower等泛称与具体植物的上下位重叠、近义/视觉近重复、目标主体是否明确，以及哪些preview可以独立预留。历史清单并不能证明没有任何未记录的旧使用；“全新”严格指本次合并的可追溯历史。ImageNet来源排除也不保证网络预训练从未见过该语义或近重复图片。

## 5. 下一版建议（未执行）

1. 固定五类及标签判据，先做标签/图像审核，不以模型准确率决定保留哪些概念。保留审核前后清单和排除原因。
2. 可考虑每类20个全新概念×每概念4张目标，共400张目标；每概念至少额外预留1张同概念preview。五折每类每折4概念、16目标，各折80目标，避免现有小折和不等权问题。该数量是库存支持的设计候选，不是功效保证。
3. 植物在manual口径有28个全新概念，初步可留8个供开发/预览或审核损耗。泛称合并与视觉审核可能降低数量，因此不宣称已锁定400图。若只有human口径的20个植物，则没有同样的开发概念余量，应相应减小正式规模，而不是事后混用标签。
4. 其他类别的多余候选用于开发和留出的确认集，不需要强行让植物达到100概念，也不必立刻外部搜图。THINGS和ImageNet分别分组采样，不再要求概念交集或同样本数。
5. 正式冻结前明确主要读出/窗口/对比。早期内容效应是值得检验的假设，尚不是已确认结论；可把宏平均AUC作为与人类实验对照的重点，ACC继续保留。避免把所有层、时间和指标中任一个正值当成功。
6. 若要宣称超出描述性的识别优势，另行预先设计概念层面、包含重新拟合的统计推断与多重比较控制。明确“跨刺激概念”泛化，不把固定网络结果直接称为跨人群神经机制证据。

本轮工作没有修改已冻结实验计划，也没有生成新fold或正式样本选择。正式实施应使用新实验目录。
