# PCoder4 → PCoder5 → FC1 → FC2 临时 Hebbian 串联方案

## 1. 四层通路与记忆时序

在同一个 Predify VGG16 的每个外层步 `t` 内，依次更新 `rep4`、`rep5`、FC1 和 FC2。PCoder4 和 PCoder5 在各自的预测模块读取本层输出前施加侧向更新，所以 `rep4` 进入下游卷积，`rep5` 同时进入 `prd5` 和原池化/FC 通路。原有递归、预测误差和预测编码系数沿用卷积实验的配置。FC1 更新后的原 4096 维向量经过原线性层、bias 和 ReLU，生成 FC2 的实际输入。FC2 更新后的原 4096 维向量进入最终读出。FC 的侧向状态在每个外层步从当前输入重算，临时记忆跨 target 步只读。以实验包装器接入，关闭旧 Hebbian 更新，主干权重、预测模块权重和 FC 权重均冻结。

| 位置 | 临时记忆来源及作用位置 | 首轮设置 |
|---|---|---|
| PCoder4 | `rep4 → W4 → rep4` | 原 512 通道，沿用已验证的非负口径 |
| PCoder5 | `rep5 → W5 → rep5` | 原 512 通道，使用本层独立图和定标。`prd5` 是对 `rep4` 的预测，继续走原反馈路径 |
| FC1、FC2 | 每层用自己的原 FC preview 响应编码并建图 | 沿用每层 2,112 参数的轻量 SAE 结构。记忆匹配及增益方向由 SAE 辅助计算，原 4096 维活动用于前馈和读出 |

PCoder5 的首轮操作定义为 `M(ReLU(rep5)) + min(rep5, 0)`，其中 `M` 是正活动上的侧向更新。这样，若基线存在负分量，可以保留该分量并单独量化正活动抑制。关闭干预或零记忆时直接旁路，以便与旧 PCoder4-only 基线做逐步对齐。卷积图均沿用柱内全体非自连接候选、八邻域柱间 mutual top-32，在累积迹上剪枝。两层在各自的空间分辨率上独立计算。

1. **Trial 初始化。** 恢复同一灰屏 PCoder 快照，清空四份记忆、临时缓存和写计数。每个 target 的 Exact/Different 共用相同 target 图像、位置和初始化，只替换配对的关键 preview 图像。
2. **两段 preview，各 2 个外层步。** 第一段用零记忆，段末同步截取各层实际输出后写入。第二段两 PCoder 用首段记忆做仅抑制，固定 `λ4=.03、λ5=.015`。FC 两层从当前真实通路读取段末响应并写入，preview 时旁路 FC 侧向更新，沿用独立 FC 的写入时序。四层均在段末执行 `W ← .5W + .5H`，卷积柱间保留对应未剪枝迹，最终冻结权重相当于 `0.25H₁ + 0.5H₂` 后按图规则处理。
3. **Target 15 个外层步。** 接续 preview 的 PCoder 状态，冻结四份 `W`，每个外层步每个启用层先做 5 个侧向抑制步。增益候选在第 5 步末态 `p` 上只施加一次 `p[1+ε(u−mean_p(u))]`，`u=tanh(q/c)`。Conv 按柱、FC 按整张图用 `p` 加权中心化。比较同一历史的参数时共用 preview 末态和记忆。记录外层 `t0–14` 与内层 `s1–5` 两套步号。
4. **两个参照。** 同 preview 末态和 `W`、仅在 target 将四层算子旁路，用于估计 target 读取效应。另保留从 preview 起关闭四层记忆的同历史对照，以及 2+2 灰屏且零写入的无 preview 参考，用于估计完整协议效应和 PCoder 历史本身的影响。

## 2. 验收、定标和小批量搜索

**接线验收。** 每数据集先用训练折 1–2 个 target 检查全关、只开 PCoder4、只开 PCoder5、只开 FC 和四层全开。用旧协议分别对齐 PCoder4 的仅抑制轨迹和独立 FC 的桥接输出，再接入新协议。检查四处真实张量、15 步非有限值/异常全零、每个 preview 边界写一次、无 preview 写零次、target 前后权重哈希一致，以及重放和改变 trial 顺序后一致。只切换 FC 时，PCoder 的 `rep/prd/grd` 应一致。单独对 PCoder5 记录负值占比、正活动、预测误差及 `prd5` 幅度，确认实际有作用且零记忆旁路能对齐。以上是后续执行的验收项。

**数据与定标。** 用卷积分支清单的 folds 1–3 训练和定标，fold 4 的 clean 开发批量固定为 ImageNet 16、THINGS 20 个 target。fold 0 留给之后的独立复核。目标和两段 preview 都按概念与图像哈希审计。首轮搜索用训练折中已有的 24／30 个 target 子集，所有配置用同一批 Exact/Different。旧独立 FC 代理的训练范围包括正式 fold 4，本轮以经过隔离审计的 folds 1–3 联合通路响应重新拟合相同的轻量 SAE，并定标每个数据集×层的 `κ₀`、增益 `c` 和卷积活动尺度。`κ₀` 取训练查询的正匹配均值，`c` 取仅抑制末态活跃单元的 `q` RMS。先以干预关闭的训练轨迹拟合代理和初始定标，再以参考抑制轨迹定标 `c`，随后冻结全部常数。固定分类头在同一训练划分的四层关闭通路上训练或复用来源匹配的旧头。

| 阶段 | 参数 | 条件数 |
|---|---|---:|
| A，四层仅抑制 | `ε=0`。`(λ4, λ5)` 取 `(.015,.0075)`、`(.03,.015)`、`(.045,.0225)`，与 `λFC1=λFC2` 的 `.015`、`.03`、`.045` 交叉 | 9 |
| B，小增益对照 | 固定 A 的入选 λ。保留 A 的 `ε=0`，另比只开 PCoder4 增益、只开 PCoder5 增益、只开 FC1+FC2 增益，启用位置 `ε=.005` | 3 个新增 |

`λ5` 从 `λ4` 一半起步，是为新增层设的保守搜索范围。`λ` 网格只改变 target 读取，preview 使用固定设置。首轮固定连接、5 个侧向步、预测编码系数、写入衰减和布局。A 的 9 点对应 972 个 target×历史×参数结果，两数据集合计。若只为筛参缓存同一 PCoder 参数下真实产生的 FC1 输入和两段 preview 端点，A 只需 324 条不同的 target 主干轨迹，FC1→FC2 仍按原权重重算。入选点冻结前用全程真实串联对齐缓存结果。B 中改变 PCoder 增益的条件重新跑递归。

**选择规则。** 先排除数值异常、死层或最终读出明显退化的点。工程筛选建议以同 preview、target 四层旁路为参照，固定 FC2 的逐步平均 BA 降幅限 1 个百分点，真实类 margin 的平均下降限该数据集训练基线 margin 标准差的 0.10 倍，按两个历史的早期和中晚期分别检查。对通过的 A 点，看 PCoder4、FC1、FC2 在 `t5–14` 相对同 preview 四层旁路的重复抑制增量，以及相对同历史旁路的最差 Fisher 变化。优先选择两数据集抑制方向一致且处于抑制/几何权衡前沿的点，再以最差层 Fisher、margin 和较低 λ 决定。PCoder5 单列结果。若新增 PCoder5 是唯一明显的抑制或传播瓶颈，在训练侧额外单调 `λ5` 两点（A 入选值的 0.5 倍、1.5 倍），锁定其余三层再决定是否调整。没有满足读出约束的点时，保留参考点作诊断。B 的增益只有在同位置固定输入的 Fisher 改善、完整串联也显示一致方向、且保住 A 的抑制和读出时才晋级。两数据集共用参数点，各自定标，冻结后只用 clean 开发批量复核参照、选中仅抑制点及通过筛选的增益点。

**报告。** 四处记录实际算子输入和输出、活动、密度、L2 归一化后类内/类间散度与 Fisher。重复抑制使用同一 target 的 `100×(1−Exact/Different)`，同时报告减去同历史无 Hebbian 参照后的变化。PCoder5 活动以正部分为主，补充原带符号图的几何。四层均报告 `t0–4`、`t5–9`、`t10–14`，重点看 PCoder4 中晚期和 FC1→FC2 的差异。固定 FC2 SVM 报告逐步准确率/BA、AUC、真实类别 margin，必要时在冻结后用训练折拟合一个跨历史及对照共享的读出作诊断。配对区间按类别内概念成块重采样，整条 trial 和所有历史、条件、时间步一起抽取。

## 3. 基本串联通过后再做的验证

| 问题 | 对照与判读 |
|---|---|
| 卷积和 FC 的抑制会叠加还是互相抵消？ | 在同一 preview 末态及四份 `W` 上做 target `PCoder组关/开 × FC组关/开`。对 `log(活动Different/活动Exact)`、Fisher 和 margin 计算联合效应减去两组单开效应。PCoder4-only 与 PCoder4+5 的对照单独报告，定位新增 PCoder5 的贡献。 |
| 抑制是匹配变强，还是输入活动及传播变了？ | 同一 target 的同一输入交换 Exact/Different 的记忆，逐层记录 `κ`、`μ+σ`、阈值和活动。对冻结记忆做目标前通道或 latent 置换，同一 target 两历史共享排列，保持图结构。以同一输入和 `W` 比较增益前后，再对比真实闭环。重点检查 PCoder5 改变 `prd5` 后，PCoder4 的差异是否从 `t+1` 开始出现。 |
| 为什么增益没带来类别 sharpening？ | 以同 `p,W` 的 `ε=0/.005` 做局部等活动对照，逐层看类内和类间散度。此前 FC 加增益后类内扩张超过类间，Conv4 两者一起收缩，且 ImageNet 的微小 Fisher 收益未在 THINGS 复现。用等均值缩放检查 FC 固定 margin 对活动幅度的敏感性，并在原 FC1→FC2 桥上分别回放 FC1 干预前后的输出，区分桥接效应与 FC2 本层增益。 |
| FC 在 preview 阶段也参与读取，会改变什么？ | 固定入选 target 参数，对比第二段 preview 的 FC 旁路和 FC 仅抑制。两者保持相同 PCoder preview 路径，检查第二次写入的 FC1/FC2 记忆、target 的匹配和实际读出。冻结方案后用保留的 fold 0 做 clean 复核，再扩展历史类型或退化条件。 |

已有独立结果用于设定搜索范围。原通道 Conv4 仅抑制的中晚期 Exact/Different 抑制约 0.12%–0.15%，独立 FC 两层约 0.41%–0.91%。抑制后单次 `ε=.005` 在固定输入下保留活动量，仍出现 FC Fisher 小幅下降，Conv4 的微小收益也随数据集变化。串联后的类别 sharpening 以实际干预层的配对几何为准，最终准确率用于功能检查。
